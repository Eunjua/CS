## 분석 규칙

### 카테고리 분류

태그명의 접두사를 기준으로 분류한다. 복합 태그(`제안/아카데미_신규과목`)는 `/` 뒤 부분을 기준으로 분류한다.

| 카테고리 | 조건 |
|--------|------|
| 아카데미 | `아카데미_`로 시작 |
| 기관 | `기관_`으로 시작 |
| 요양 | `요_`로 시작 |
| 일반 | `일반_`으로 시작 |
| 오류 | 태그명에 `오류` 포함 (🔴 알림 대상) |
| 기타 | `_`가 없는 태그 (운영시간외전화인입, 콜백/ 등) → 카테고리 표에서 제외 |

> ⚠️ report.json은 태그별 집계 데이터로, 1건의 문의에 여러 태그가 붙을 수 있어 태그 건수 합계 ≠ 실제 문의 건수다. 따라서 총계 섹션은 출력하지 않는다.

### 이상 태그 판정

두 주차에 모두 존재하는 태그만 비교한다.

- **급증**: 전주 대비 증가율 +30% 이상 AND 증가량 3건 이상
- **급감**: 전주 대비 감소율 -30% 이상 AND 감소량 3건 이상
- **신규**: 전주 0건 → 이번 주 등장
- **오류**: 태그명에 `오류` 포함 → 급증/급감 여부와 무관하게 🔴 표시
