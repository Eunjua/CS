- **영문명**: 자격증명을 적절히 영역한다. 확실하지 않으면 번역 후 `[확인 필요: 영문명 검토]` 표시
- **직무내용**: 해당 자격증 소지자가 실제로 수행하는 직무를 구체적으로 작성한다 (200자 이내). 확실하지 않으면 `[확인 필요: 직무내용 검토]` 표시
- **검정기준**: 직무내용을 바탕으로 **이론적 지식만** 평가하는 기준을 작성한다 (200자 이내). 실기·실습 관련 내용은 절대 포함하지 않는다.
- **검정과목**: 사용자가 제공한 커리큘럼을 분석하여 **3개 내외의 과목명**으로 묶는다.
  - 강의 내용의 주제별 흐름을 파악해 자연스럽게 분류한다.
  - 과목명은 간결하고 공식적인 명칭으로 작성한다 (예: "병원동행 서비스 이론", "응급의료 기초지식").
  - **"실무", "현장", "실전", "실기"** 등의 단어는 절대 과목명에 사용하지 않는다.
  - 실습·실전 성격의 강의도 이론적 명칭으로 재해석한다 (예: "실무" → "운영론", "이해", "직업윤리론" 등).
