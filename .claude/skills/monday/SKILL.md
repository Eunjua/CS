# 월요일 루틴

스킬 4개(`/요청기록`·`/kr`·`/알프`·`/voc`)를 **정해진 순서로** 부르고, 파일 나르기·시트 버튼은 스크립트가 대신한다.

## 은주가 하는 일 — 그 밖은 스킬이 한다

1. **채널톡 export 2개**(아카데미·케어파트너 채널)를 `채널톡/` 폴더에 그냥 넣는다(폴더 만들 필요 없음). 드라이브·`voc-원문`·`상담내역`에는 **넣지 않는다**.
2. `/월요일` 부르기 — 시작할 때 **채널별 관여율·해결률(지난주 값)**을 알려준다
3. 중간 판단: 요청기록 줄 확인 · ALF 노션 기록 문구 확인 · VOC 주제 고르기 · VOC 초안 승인
4. **ALF 개선 작업(규칙·docs 수정, 채널톡 AI와 태스크 고치기·게시)은 월요일에 하지 않는다.** 따로 세션을 열어 "N차 개선 진행"이라고 부른다(2026-10-26 은주 결정 — 한 세션에 VOC와 섞이면 지금 무슨 일을 하는지 구분이 안 됨)

## 순서 — 앞 단계가 끝나야 다음이 맞다

0. **파일 확인.** `채널톡/` 바로 아래(`처리완료/` 제외)의 xlsx 목록과 채널(`Manager data` channelId 201411=아카데미, 87358=케어파트너)을 알린다. 없으면 1번만 하고 "채널톡 export를 `채널톡/` 폴더에 넣어주세요"라고 멈춘다.
   **같은 메시지에서 은주에게 채널별 관여율·해결률을 묻는다**(예: "아카데미 93 / 56.4, 파트너 65 / 30" — export 기간인 지난주 값). 받은 값은 3번 `/kr`(KR2)과 4번 `/알프`(노션 추이 DB)가 같이 쓴다 — 다시 묻지 않는다.
1. **요청 건수 채우기.** 지난주 월~일 중 요청 기록 시트에 없는 날을 찾아 `/요청기록` 절차로 하루씩 채운다(그 스킬의 "먼저 보여주고 넣기" 그대로). KR1 분자가 여기서 나온다.
2. **대시보드 v2 업로드·집계** — 시트 버튼 3개 대신:
   ```bash
   python3 .claude/skills/monday/v2_sync.py all 채널톡
   ```
   단계별 메시지(불러온 건수·중복·만족도 새 응답·집계)를 요약해 알린다. 실패 파일이 있으면 멈추고 알린다.
3. **KR 갱신** — `/kr` 절차. 0단계 "v2 집계 확인"은 2번에서 끝났다.
4. **알프 분석·노션 기록** — `/알프`의 **분석·기록 모드**로만 돈다(그 스킬 「두 가지 모드」). 입력은 `채널톡/` 바로 아래 파일(채널별 따로).
   - 개선 제안은 만들되 **반영하지 않는다** — 규칙 파일 수정 승인을 받지 않고, 채널톡 탭을 띄우지 않는다. 제안은 개선로그 「개선 액션」과 📊 개선점 DB(`미확인`)에 남기고 끝낸다.
   - 노션 기록·`.알프완료` 표시까지 끝나면 바로 5번으로 넘어간다.
5. **VOC 리포트** — `/voc` 절차.
6. **하루 메모 페이지 건수 채우기** — 상담원별 메모 페이지(지수·민강·지영)의 응대량 탭 숫자를 지난주 일요일까지 채운다.
   ```bash
   python3 .claude/skills/monday/memo_counts.py 채널톡 --out "$CLAUDE_JOB_DIR/tmp/memo_out"   # 잡 폴더가 없으면 아무 임시 폴더
   ```
   - 페이지 목록·주소는 `.claude/skills/monday/memo_pages.local.json`(git에 안 올라감). 없으면 이 단계를 건너뛰고 알린다. 민강·지영님(전화)은 같은 기준 `split`으로 통화를 셋으로 나눈다 — 부재중=`mi`(회색, 상담원이 걸었는데 연결 안 된 통화, 태그 상관없음) · 인터뷰=`ac`(주황, 연결된 통화 중 태그가 인터뷰뿐) · 일반=`pt`(그 밖의 연결된 통화). 고객이 걸었는데 못 받은 통화는 세지 않는다.
   - 페이지마다 `ArtifactData` `get`(collection `stats`, doc `daily`)으로 version을 읽고, `update`에 `file_path`=`<out>/<key>.json`·`if_version`을 넣는다. update는 병합이라 **export 기간 날짜만 덮어쓰고 그 전 날짜는 그대로**다.
   - 기간은 export가 빠짐없이 담은 첫날 ~ 지난 일요일. 집계 중간인 날(이번 주)은 넣지 않는다 — 다음 월요일에 한 주를 통째로 넣는다.
   - 스크립트가 출력한 사람별 기간·평일 평균을 한 줄씩 알린다. **메모 내용(`memos`)은 읽지 않는다** — 은주가 요청할 때만.
   - 이미 그 일요일까지 들어가 있으면(`through`가 같으면) 건너뛴다.
7. **처리완료로 옮기기.** 2~6번이 **모두** 끝났을 때만 `채널톡/` 바로 아래 xlsx를 `채널톡/처리완료/`로 옮기고 `채널톡/.알프완료`를 지운다. 하나라도 못 끝났으면 옮기지 않는다(다음에 이어서 쓴다).
8. **마무리 요약** — 한 장으로: 올린 파일·KR1 비율과 목표 대비·ALF 회차 결과·VOC 리포트 노션 링크·**신뢰 한 줄**(신뢰 문의 비중·1위 원인·결제 후 환불·「자격증 신뢰 추이」 대시보드 갱신 여부)·하루 메모 페이지 건수 갱신(어디까지 들어갔는지)·남은 일.
   - **ALF 개선 작업 안내 한 줄**: 이번 회차에 반영 대기 중인 제안 건수(태스크 N · 규칙 N · docs/FAQ N)와 "새 세션에서 `/알프 N차 개선 진행`이라고 부르면 이어서 해요". 끝으로 "GitHub에 올릴까요?"(CLAUDE.md Git 규칙).

중간에 끊겨도 된다 — 다시 부르면 끝난 단계는 건너뛴다(업로드는 같은 이름 건너뜀, 알프는 `채널톡/.알프완료`에 적힌 파일 건너뜀, KR·요청기록은 이미 있는 날 건너뜀, 메모 페이지는 `through`가 지난 일요일이면 건너뜀).
