# 월요일 루틴

스킬 4개(`/요청기록`·`/kr`·`/알프`·`/voc`)를 **정해진 순서로** 부르고, 파일 나르기·시트 버튼은 스크립트가 대신한다.

## 은주가 하는 일 — 그 밖은 스킬이 한다

1. **채널톡 export 2개**(아카데미·케어파트너 채널)를 `채널톡/` 폴더에 그냥 넣는다(폴더 만들 필요 없음). 드라이브·`voc-원문`·`상담내역`에는 **넣지 않는다**.
2. `/월요일` 부르기
3. 중간 판단: 요청기록 줄 확인 · ALF 규칙 수정 승인 · VOC 주제 고르기 · VOC 초안 승인

## 순서 — 앞 단계가 끝나야 다음이 맞다

0. **파일 확인.** `채널톡/` 바로 아래(`처리완료/` 제외)의 xlsx 목록과 채널(`Manager data` channelId 201411=아카데미, 87358=케어파트너)을 알린다. 없으면 1번만 하고 "채널톡 export를 `채널톡/` 폴더에 넣어주세요"라고 멈춘다.
1. **요청 건수 채우기.** 지난주 월~일 중 요청 기록 시트에 없는 날을 찾아 `/요청기록` 절차로 하루씩 채운다(그 스킬의 "먼저 보여주고 넣기" 그대로). KR1 분자가 여기서 나온다.
2. **대시보드 v2 업로드·집계** — 시트 버튼 3개 대신:
   ```bash
   python3 .claude/skills/monday/v2_sync.py all 채널톡
   ```
   단계별 메시지(불러온 건수·중복·만족도 새 응답·집계)를 요약해 알린다. 실패 파일이 있으면 멈추고 알린다.
3. **KR 갱신** — `/kr` 절차. 0단계 "v2 집계 확인"은 2번에서 끝났다.
4. **알프 분석** — `/알프` 절차. 입력은 `채널톡/` 바로 아래 파일(채널별 따로).
5. **VOC 리포트** — `/voc` 절차.
6. **처리완료로 옮기기.** 2~5번이 **모두** 끝났을 때만 `채널톡/` 바로 아래 xlsx를 `채널톡/처리완료/`로 옮기고 `채널톡/.알프완료`를 지운다. 하나라도 못 끝났으면 옮기지 않는다(다음에 이어서 쓴다).
7. **마무리 요약** — 한 장으로: 올린 파일·KR1 비율과 목표 대비·ALF 회차 결과·VOC 리포트 노션 링크·남은 일. 끝으로 "GitHub에 올릴까요?"(CLAUDE.md Git 규칙).

중간에 끊겨도 된다 — 다시 부르면 끝난 단계는 건너뛴다(업로드는 같은 이름 건너뜀, 알프는 `채널톡/.알프완료`에 적힌 파일 건너뜀, KR·요청기록은 이미 있는 날 건너뜀).

- 웹앱 주소·열쇠는 `gas-v2/.local.json`. 없으면 2번을 건너뛰고 "시트에서 버튼 3개 눌러주세요(만족도는 [아니오])"로 대신 안내한다.
- 2026-10-07 이전 VOC 원문은 `voc-원문/`에 그대로 있다(옮기지 않음). `cs-triage/상담내역/`은 10/7에 정리했다.
