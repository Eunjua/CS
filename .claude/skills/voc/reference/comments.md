# 설문 자유의견 — 매주 (진행순서 4·5·7번에서 읽는다)

2026-11-02 은주 결정: 상담 뒤 만족도 설문(「VOC,고객센터 만족도 조사」 구글폼)의 **자유의견**을 매주 리포트에 넣는다. 점수(만족도·친절도·해결 여부·대기 체감)는 이미 대시보드 v2 집계로 CX 내부용에 들어가지만, 고객이 직접 쓴 말은 빠져 있었다.

## 어디서 오나

- 폼 응답 → 대시보드 v2 「만족도원본」(`importCsat`, 상담ID·자유의견 포함) → 웹앱 `doPost` `action: comments`(열쇠 필요, `gas/voc-v2/Remote.gs` `weekComments_`)
- **주차는 상담 주차 기준** — `집계_설문`과 같은 응답 묶음이라 "해결됐어요" 비율과 나란히 읽을 수 있다. 폼 타임스탬프로 세면 수가 다르다(10/26주: 상담 주차 121 · 응답 시각 155). 상담ID가 비어 있는 응답(누적 215건)은 들어오지 않는다.
- 의견에는 이름·전화번호가 섞일 수 있어 **열쇠 없는 `doGet`에는 두지 않는다**(그 주소는 공개 저장소 `analyze.py`에 있다).

```bash
python3 .claude/skills/voc/comments.py <주차> --out <저장소 밖 폴더>/c   # raw_의견.txt · chunk_의견N.txt · links_의견.md
python3 .claude/skills/voc/tally.py <같은 폴더>/c 의견                   # 이유별 건수
python3 .claude/skills/voc/comments.py --cross <같은 폴더>/c           # 이유별 '해결 안 됨·일부' (5번 표 열)
```

- 3자리 이상 숫자는 `[숫자]`로 가린다(`sample_chats.mask`). 이름은 못 가리므로 인용할 때 다시 본다.
- 인사·"없음"만 있는 의견은 분류에서 빼고 건수만 출력한다. 칭찬은 남겨서 `칭찬`으로 센다.

## 분류 기준표 (하위 에이전트에게 그대로 준다)

```
설문 자유의견 기준표 — 의견마다 category 하나, mentions 여러 개.
- AI답답 — AI(봇) 상담이 답답하다·단답이다·같은 답만 반복한다·사람과 상담하고 싶다
- 상담원태도 — 상담원이 불친절·사무적·성의 없다·고객 탓을 한다·윗글 보라는 식
- 대기연락 — 전화 대기가 길다·연결이 안 된다·다시 연락 준다더니 안 왔다·답이 늦다
- 미해결 — 아직 해결되지 않았다·약속한 처리(서류·발송·환불)가 안 됐다(누구 탓인지 말하지 않음)
- 제품요청 — 자격증·앱·강의·시험·결제 화면에 바라는 것(사진 넣어 달라·더 쉽게 등)
- 정보부족 — 수강 전·결제 전에 미리 알았어야 할 안내가 없었다(취업 여부·비용·조건)
- 비용 — 비싸다·가격 부담
- 칭찬 — 친절했다·도움이 됐다·감사(내용 없는 인사는 이미 걸러짐)
- 기타 — 위에 없음, note에 설명(설문과 무관한 문의를 남긴 것 포함)
mentions 후보: ["AI상담","상담원","전화","채팅","대기","자격증","사진","결제","비용","취업","재문의"]
```

에이전트 프롬프트는 [data.md](data.md) 「원문 전체 분류」 틀 그대로 — 주제 `의견`, 필드는 `chat`·`category`·`mentions`·`quote`(60자, 이름·숫자 빼고)·`issue`·`note`. `outcome`·`stage`는 쓰지 않는다(헤더의 `해결=`이 처리 결과다).

## 리포트 자리 — 독자는 팀 전체

| 이유 | 어디에 |
|---|---|
| AI답답 · 제품요청 · 정보부족 · 비용 · 미해결 | **팀 공유용 5번 「고객이 설문에 남긴 말」** — 이유별 건수 표 + 고객 한 마디(가린 것) + 해결 여부와 함께 |
| 대기연락 · 칭찬 · 기타 | CX 내부용 「4. 상시 지표」 아래 건수 한 줄 |
| **상담원태도** | **리포트에 넣지 않는다** — 건수와 상담 링크를 은주에게만(응대 이슈와 같은 방식) |

- 건수는 `tally.py` 출력에서만. 이유별 "해결 안 됨·일부"는 `comments.py --cross` 출력을 쓴다.
- 신뢰 지표판 원인과 같은 이야기(사진·비용·취업)는 해당 원인별 카드에 "설문에서도 ○건"으로 한 줄 이어 준다.
- 상담 링크는 `links_의견.md`를 5번 아래 토글로 둔다 — 저장소 파일에는 쓰지 않는다.
- 분류할 의견이 10건 미만인 주는 표를 쓰지 않고 고객 한 마디 2~3개만 둔다.
