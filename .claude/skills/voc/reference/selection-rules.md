# 선별 규칙 (`analyze.py`에 박혀 있음)

문턱을 바꾸려면 `analyze.py` 위쪽 상수만 고친다.

| 규칙 | 조건 | 왜 이 값인가 |
|---|---|---|
| 급증 | 증가 10건 이상 **그리고** +30% 이상 | 주 1,200건 규모에서 %만 보면 3→6건이 +100%로 올라와 진짜 신호를 덮는다 |
| 급감 | 감소 15건 이상 **그리고** −30% 이하 | 감소는 급증보다 덜 급하니 문턱을 높였다 |
| 신규 | 직전 4주 0건 **그리고** 이번 주 5건 이상 | 1~2건은 일시적 노이즈 |
| 급부상 | 직전 4주 평균 2건 이하가 이번 주 8건 이상 **그리고** 3배 이상 | 낮게 깔려 있다 튄 건 증가 폭이 작아 급증에 안 걸린다 |
| 기타계열 | 태그에 '기타' 포함 **그리고** 5건 이상 증가 | 분류 공백 신호라 문턱을 낮게 |
| 연속추세 | 주간 지표(만족도·친절도·총건수) 3주 연속 같은 방향 | 전주 대비로는 안 잡히는 완만한 변화 |
| 태그추세 | 태그가 3주 연속 같은 방향 **그리고** 총 변화 5건 이상 | 매주 문턱 아래여도 방향이 굳어지는 게 있다 |

## 태그 신호 고르는 순서 (위가 우선, 최대 3개)

1. `신규`·`급부상` — 새 이슈 신호라 제일 강하다.
2. `기타계열` — 기존 분류에 안 맞는 문의가 들어오고 있다는 뜻. 여러 개면 묶어서 한 덩어리. `급증`에도 나오면 여기서 한 번만.
3. `급증` — 증감 큰 순.
4. `연속추세`·`태그추세` — 총변화 큰 것 위주.
5. `급감` — 좋아진 걸 수도, 경로가 막힌 걸 수도 있다.

**같은 원인으로 설명되는 신호는 한 덩어리로 묶는다** — 예: 회의록 태그 결정 하나로 신규 태그 여러 개와 `기타` 급감이 같이 생긴 경우.

## 제외 태그

`AI`, `AI/*`, `태그없음`, `인터뷰`. `AI/*`는 워크플로우 상태값이라 늘어도 문제가 아니고, `태그없음`은 상시 지표로 따로 보고, `인터뷰`는 고객 문의가 아니라 우리가 만든 인입이다.

**`AI상담/*`는 빼지 않는다.** 이름이 비슷하지만 사람이 붙인 봇 품질 신호(오안내·이관안함·안내안함·고객이탈)라 늘면 반드시 본다.
