# 규칙이 생긴 사례

스킬을 실행할 때는 읽지 않아도 된다. 규칙을 바꿀지 판단할 때, "이 규칙 왜 있지?"가 궁금할 때 본다.

## 2026-08

- **급부상 규칙 (08-18):** `자격증/오배송`이 1·2·2·2 → 11건(+9)으로 튀었는데 급증(10건) 문턱에 안 걸려 놓쳤다.
- **태그추세 규칙:** `자격증/정보수정` 21 → 35 → 42처럼 매주 문턱 아래인데 방향이 굳어지는 태그가 있었다.
- **인터뷰 태그 제외 (08-18):** 고객 문의가 아니라 우리가 만든 인입이라 은주 지시로 뺐다.
- **대기 체감 따로 보기 (08-18 주차):** 만족도·친절도·해결률이 전부 올랐는데 "너무 오래 기다렸어요"만 9.3% → 14.0%로 역행했다.
- **상담원별 표 ≠ 개인 성과 (08-18):** 6주를 보니 채팅이 전화보다 6주 중 5주 낮았다(격차 0.00~0.49). 응대량 불균형(채팅 1명 465건 vs 전화 2명 365건)도 채널당 인원 배치 문제였다.
- **태그 체계 변경 구분:** 8월 첫 주 `AI` 태그 18 → 0은 문의가 아니라 체계 변경이었다.
- **부재중 분모:** 8월 3주 전체 대비 19.6% ↔ 전화 대비 38.0%. 회의에서 심각도가 절반으로 보였다.

- **팀원 업무 목록 대신 VOC 연결 조치만 (09-14 합의):** 업무 목록은 리포트를 흐리고 평가처럼 읽힌다.
