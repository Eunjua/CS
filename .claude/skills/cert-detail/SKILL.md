# 자격증 상세 문서 추가 스킬

케어아카데미에 신규 과정이 생기면 `cs-triage/ALF_docs/자격증상세/{자격증명}_{급수}.md`를 만들고, **같은 내용을 [자격증 상세 시트](https://docs.google.com/spreadsheets/d/1jXPEfaol5hhIklzjTa8INudskEnVvKo9urHr7vO9MSg/edit?gid=0)에도 한 줄 추가한다.** 교안링크가 있으면 [발송 도구 템플릿 시트](https://docs.google.com/spreadsheets/d/1CE4RQ2MKPsyA4hGHBT-p8TPCDK8D5VqfmVbc5mFOgFs/edit?gid=0)에 교재 발송 문자 템플릿도 자동으로 생긴다. 그다음 **채널톡 두 채널(케어아카데미·케어파트너) ALF 도큐먼트에 같은 아티클을 게시하고, [CS 관련 공유 사항 보드](https://claude.ai/artifact/1gy83nc1q2AsuYKmUibems)에 콘텐츠 카드를 넣는다.** 마지막으로 **[기출문제 답안지](https://claude.ai/artifact/QA3vTTxhFWudaDt3ykCmMj)를 기출문제 시트 기준으로 다시 올린다.**
이 폴더는 **ALF 봇이 "이 자격증 따면 무슨 일 해요 / 어디서 써요 / 강의 어디서 들어요" 문의에 답할 때 쓰는 사실 잣대**다. 여기 없으면 봇이 답을 못 한다.

## 먼저 확인된 것 (다시 조사하지 말 것)
- **저장소 안에는 자격증 마스터 목록 파일이 없다.** 각 md가 독립이라 저장소에서는 **새 파일 하나만 추가하면 끝**이다. 다른 문서를 같이 고칠 필요 없음. (저장소 밖 목록은 위 시트 — 4단계에서 자동으로 채운다)
- 상위 `ALF_docs/*.md`(수강·시험·발급 정책)에는 과목별 강의 수가 하드코딩돼 있지 않다. 건드리지 말 것.

## 1. 정보 받기
은주는 보통 **상세페이지 URL·교육자료 PDF 링크·기관(ncs 등)·아카데미 상세페이지 시트 탭 링크**를 순서 없이 한꺼번에 준다. 상세페이지 URL이 있으면 **먼저 아래 스크립트로 읽고, 없는 것만 묻는다.** 다 모일 때까지 기다리지 않는다.

```bash
python3 .claude/skills/cert-detail/from_detail_page.py https://www.carepartner.kr/academy/77
```

출력에서 바로 쓰는 값:
- `name` 과정명(`시니어요가지도사 1급`) · `org` 발급 기관 · `registerNumber` 등록번호 · `lectures` 강의 수
- `hours` **강의 시간** — 운영 중 영상 길이를 다 더하고 초는 버린 값(`4시간 47분`, 딱 떨어지면 `7시간`). 상세페이지 화면에는 안 보이고 페이지 데이터에만 있다. 기존 시트 값도 이 방식이다(11/4 확인: 세탁기분해세척관리사 4시간 35분 54초 → `4시간 35분`). 시트에만 넣고 md에는 안 쓴다. **이수증 화면(`cert/`)이 이 칸을 그대로 찍으니** 숫자만(`40`)이나 다른 표기로 바꾸지 말 것
- `shortDescription`·`description`·`usage`·`jobs`·`videoTitles` — 소개·주요 업무·활용 분야 초안 재료(`videoTitles`가 곧 커리큘럼)
- 이 값들은 [아카데미 상세페이지 시트](https://docs.google.com/spreadsheets/d/1jC36YwbLRpCdcdC5Bj9jjgXVNsHOkw7JRpy4YgR8zAI/edit)의 과정 탭과 같은 내용이다. 상세페이지가 아직 안 열렸으면 그 탭을 대신 읽는다: `curl -sL "https://docs.google.com/spreadsheets/d/1jC36YwbLRpCdcdC5Bj9jjgXVNsHOkw7JRpy4YgR8zAI/gviz/tq?tqx=out:csv&gid={탭 gid}"` (강의 시간은 이 시트에 없다 → 비워 두고 상세페이지가 열리면 `{"name":"...","hours":"..."}`만 다시 보낸다)

은주에게서만 받는 값:
- 교육자료 PDF — 구글드라이브 링크
- 기관을 따로 말하면(`ncs`) 스크립트의 `orgCode`와 같은지만 확인. 다르면 은주에게 묻는다

선택:
- 특이사항 — 이름이 비슷한 국가자격 등 혼동 포인트가 있을 때만

## 2. 파일 쓰기 (템플릿)

```markdown
# {자격증명} {급수} 자격증 상세

## 1. 기본 정보
- 자격증명: {자격증명}
- 급수: {급수}
- 발급 기관: {기관}
- 등록번호: {등록번호}
- 강의 개수: {N}강

## 2. 자격증 소개
{2~3문장. "○○는 ~하는 ~ 전문인력입니다." 형태로 끝맺는다.}

## 3. 주요 업무
- {3개 내외}

## 4. 활용 분야
- {기관·시설명 한 줄에 하나}

## 5. 강의 상세페이지
- 강의 상세 페이지에서는 자격증 과정 소개 및 수강에 대한 상세 내용을 확인할 수 있습니다.
- {자격증명} 상세 페이지: {URL}

## 6. 교육자료
- {자격증명} 교육자료(PDF): {드라이브 링크}
```

## 3. 지킬 규칙
- **파일명은 `{자격증명}_{급수}.md`** — 공백 없음. 예: `실버케어지도사_1급.md`
- **섹션 번호는 유동적이다.** 특이사항이 있으면 `## 5. 특이사항`을 끼워 넣고 상세페이지·교육자료를 6·7로 민다. 없으면 위 템플릿 그대로 5·6.
- **드라이브 링크는 `?usp=sharing`을 떼고 `/view`로 끝낸다.** 기존 파일 전부 그 형식이다.
- **상세페이지가 아직 없으면** 5번을 `- 강의 상세 페이지는 아직 오픈 전입니다.` 한 줄로 대체한다. 섹션을 통째로 빼지 말 것 — 나중에 URL만 채우면 되게 자리를 남긴다.
- **교안이 없다고 하면** 교육자료 섹션을 `- {자격증명}는 별도 교육자료(PDF)가 없습니다.` 한 줄로 둔다(섹션은 남긴다). 시트 `pdfUrl`은 `""`.
- **주요 업무를 소개 문구에서 뽑아냈으면 반드시 알린다.** 커리큘럼을 못 받고 추론한 것이므로 은주가 실제 강의 내용과 대조해야 한다.
- **없는 정보를 지어내지 않는다.** 등록번호·강의 수를 추측하면 봇이 고객에게 틀린 사실을 말한다. 모르면 비워두고 뭐가 비었는지 보고한다.

## 4. 시트에 추가
md 파일을 만든 뒤 바로 보낸다. 은주에게 따로 묻지 않는다 (이 단계까지가 스킬의 일).

```bash
python3 .claude/skills/cert-detail/send_to_sheet.py '{"name":"{자격증명} {급수}","org":"{기관}","lectures":"{N}강","hours":"{강의 시간}","detailUrl":"{URL}","pdfUrl":"{드라이브 링크}"}'
```

- **과정명은 띄어 쓴다** — `실버케어지도사 1급` (파일명과 달리 `_` 없음). 시트는 이 값으로 같은 과정인지 찾고, **이수증 화면이 이 이름을 그대로 과정명으로 찍는다.**
- **모르는 값은 빈 문자열 `""`로 보낸다.** 상세페이지가 오픈 전이면 `detailUrl`은 `""` — "오픈 전" 같은 문구를 넣지 말 것.
- **같은 과정명이 이미 있으면 새 줄 대신 그 줄을 고친다.** 빈 값은 기존 칸을 지우지 않으니, 나중에 URL만 생겼을 때 `{"name":"...","detailUrl":"..."}`만 보내면 된다.
- 교안링크는 md와 같은 `/view` 형식으로 보낸다.
- 응답의 `values`가 실제로 시트에 들어간 값이다. 보낸 값과 다르면 은주에게 알린다.
- **응답의 `template`은 교재 발송 문자 템플릿 결과다** (웹앱이 과정 줄을 쓴 뒤 발송 도구 템플릿 시트에 알아서 만든다. 스킬이 따로 보낼 것 없음)
  - key `book_{과정명 띄어쓰기 뺀 것}`, 템플릿명 `교재 발송 ({과정명})`, 구분 문자, 본문 끝 `교재 링크:` 다음 줄에 교안링크
  - `added` = 새로 만듦 / `exists` = 같은 key가 이미 있어 **손대지 않음** (발송 도구에서 고친 문구 보호. 문구·링크를 바꾸려면 발송 도구 템플릿 관리 탭에서) / `skipped` = 교안링크가 없어 아직 안 만듦 → 나중에 `{"name":"...","pdfUrl":"..."}`만 보내면 그때 만들어짐
  - `template.ok`가 false여도 과정 줄은 이미 들어간 것이다. 템플릿 오류 문구만 은주에게 보여준다. 권한 오류면 `authorize` 재실행
- **응답의 `certSheet`는 [자격증관리 기준 시트](https://docs.google.com/spreadsheets/d/176YVTv5JM21i1p7fc6pBz_kmXnP8AYAXwseLXeBEr6g/edit) 결과다** (이것도 웹앱이 알아서 적는다)
  - `mapping` = 「자격증매핑」 탭에 `과정명 | 기관 코드` 한 줄. 코드는 한국엔씨에스자격개발원(주)→`ncs`, 한국검정평가원→`korean`, (주)한국자격개발원→`baby`. 그 외 기관이면 `skipped` → 은주에게 코드를 물어 직접 넣게 한다
  - `course` = 「발급과정」 탭 A열에 과정명만. **코드번호(B열)는 은주가 직접 채운다** — 마무리 때 꼭 알린다
  - `added` = 새로 적음 / `exists` = 같은 이름이 이미 있어 손대지 않음
  - **기준 시트에만 들어간다.** 이미 복사된 이번 달 시트(`[11월]` 등)엔 없으니, 이번 달 결제자가 생길 과정이면 그 달 시트에도 넣어야 한다고 알린다
  - `certSheet.ok`가 false여도 과정 줄·템플릿은 이미 들어간 것이다. 오류 문구만 보여준다
- **실패하면 md 파일은 그대로 두고** 오류 문구를 보여준 뒤, 시트에 붙일 한 줄(탭으로 구분)을 `pbcopy`로 복사해 두고 은주에게 빈 줄 A칸에 ⌘V를 부탁한다. `JSON이 아닌 응답`이면 대부분 권한이 풀린 것 — 스크립트 편집기(`gas/cert-detail/` 에서 `clasp open-script`)에서 `authorize` 실행 후 허용.

## 5. 채널톡 도큐먼트에 게시 (두 채널)
시트까지 넣은 뒤 바로 한다. 은주에게 따로 묻지 않는다. **화면 편집기를 직접 만지지 말고 각 채널 AI CoS에 요청한다**(편집기에서 `- `가 자동 목록으로 바뀌고 Backspace가 뒤로가기를 일으켜 초안을 망친 적 있음).

- Claude in Chrome으로 연다 — 케어아카데미 `https://channel.works/carepartner-academy/cos` · 케어파트너 `https://channel.works/carepartner/cos`. 각각 「새로운 대화」에서 시작. "11/19 이후 CoS 이용…" 팝업은 X로 닫고 넘어간다
- 넣는 곳: 두 채널 모두 **「케어아카데미」 스페이스** — 아카데미 ID `18491`, 파트너 ID `21733`(11/11 확인). 카테고리 연결 없음. 아티클 제목은 `{자격증명} {급수}`(예: `시니어취업상담사 1급`), 본문 첫 제목은 `{자격증명} {급수} 자격증 상세`
- 요청문 한 번에 담을 것: (1) 같은 이름 아티클·초안이 이미 있는지 먼저 확인하고 있으면 만들지 말고 알릴 것 (2) 스페이스 (3) 제목 (4) **"시니어요가지도사 1급처럼 실제 제목 서식과 글머리표 목록으로(#, ##, - 문자가 그대로 보이면 안 됨)"** — 기존 문서 중 냉난방기종합세척관리사처럼 기호가 글자로 박힌 것도 있어서 꼭 지정 (5) **문구를 바꾸지 말 것** (6) 초안 → 게시 전 승인 버튼
- 본문은 입력창에서 Enter가 곧 전송이라 줄바꿈 없이 한 줄로 보낸다: `[제목1] … [제목2] 1. 기본 정보 [목록] 항목 / 항목 [문단] …` 형식 + "('/'는 목록 항목 구분이야, 본문에 넣지 마.)"를 덧붙인다. 내용은 md 파일 그대로
- CoS가 초안을 만들고 원문·서식 검증 뒤 「승인」 카드를 띄우면 **Claude가 승인을 누른다**(은주가 이 스킬로 게시까지 맡김, 11/11). 검증 문구에 원문과 다르다는 말이 있으면 누르지 말고 은주에게 보여준다
- 답은 약 1분 뒤 한 번 확인한다(10초마다 반복해서 읽지 말 것). 아카데미 → 파트너 순서
- 참고: 「케어아카데미」 스페이스는 두 채널 모두 고객용 **미게시**지만 **실제 ALF 지식 참조는 켜져 있다**(11/11 두 채널 CoS로 확인, 아카데미 지식은 이 스페이스 하나뿐·파트너 지식 ID 2311981). 고객에게 공개하지 않고 ALF만 쓰는 의도된 상태라 스페이스를 게시하지 말 것. CoS가 "스페이스에 기록된 ALF 사용 설정: 꺼짐"이라고 해도 실제 참조 설정과 다른 값이라 바꿀 필요 없다. 게시 뒤 확인이 필요하면 "이 아티클이 ALF 지식 아티클 목록에 포함돼 있는지"를 묻는다
- 실패하거나 CoS를 못 쓰면 md는 그대로 두고, 어느 채널이 안 됐는지 보고한다

## 6. CS 공유 보드에 콘텐츠 카드 추가
[CS 관련 공유 사항 보드](https://claude.ai/artifact/1gy83nc1q2AsuYKmUibems)의 데이터베이스 `cards` 컬렉션에 `ArtifactData` `set`으로 새 문서를 넣는다(페이지 재게시 아님). 은주에게 따로 묻지 않는다.

- 먼저 `query`로 `type == "콘텐츠"`이고 `course`가 같은 카드가 있는지 본다. 있으면 새로 만들지 말고 `courseDoc`·`courseUrl`만 `update`(`if_version` 붙여서)
- doc_id: `a-YYYYMMDD-영문슬러그`(영문 소문자·숫자·하이픈. 예 `a-20261111-senior-job-counselor`)
- 넣는 값: `type:"콘텐츠"`, `contentKind:"새로 등록"`, `title:"신규 과목 등록: {과정명}"`, `course:"{과정명}"`(띄어쓰기), `courseUrl`(상세페이지, 없으면 ""), `courseDoc`(md 파일 전문), `services:["케어아카데미"]`, `status:"진행 중"`, `start`(오늘 날짜 `YYYY-MM-DD`), `end:null`, `tag:null`, `owner:null`, `links:[]`, `sources:[]`, `csShared:false`, **`visible:false`·`needsCheck:true`**(검토 대기로 들어감 — 상담원 공개 체크는 은주가 한다), `createdAt`·`updatedAt`(현재 밀리초)
- `response`(이렇게 안내)는 기존 카드 말투로 글머리 `• ` 줄들: "과목 소개는 아래 '강의 상세 보기' 내용으로 안내해 주세요." / "강의 상세 페이지 링크를 함께 보내 드리면 좋아요." + 특이사항이 있으면 그 혼동 포인트 한 줄, 교안이 없으면 "별도 교육자료(PDF)는 없는 과목이에요."
- 큰 본문은 스크래치 폴더에 JSON으로 써서 `file_path`로 보낸다

## 7. 기출문제 답안지 갱신
[기출문제 답안지](https://claude.ai/artifact/QA3vTTxhFWudaDt3ykCmMj)는 문제를 페이지 안에 담아 두는 방식이라 시트가 바뀌어도 저절로 안 바뀐다. 새 과정을 넣을 때마다 시트 전체 기준으로 다시 올린다. 은주에게 따로 묻지 않는다. 기출문제가 아직 시트에 없으면 건너뛰고 마무리에서 알린다.

- 원본: [케어아카데미 자격증 기출문제 데이터](https://docs.google.com/spreadsheets/d/1S00LWdnOInmkEjsp_AGWl6U7_r4G-aLI162z6QZcHrA/edit) — 탭 하나 = 과정 하나, 칸은 `exam_id·question_text·options(JSON {"1":…})·correct_answer·explanation·explanation_source`. 은주는 보기 권한만 있다(주인 김슬아)
1. Google Drive `download_file_content`로 시트를 xlsx로 받는다 (`exportMimeType: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`). `read_file_content`는 칸 값이 안 나와서 못 쓴다
2. `Artifact` `read`(url 위 링크)로 지금 페이지를 받는다 — 결과에 저장된 HTML 파일 경로가 나온다
3. `python3 .claude/skills/cert-detail/build_answer_sheet.py <xlsx> <받은 HTML> <스크래치/answer-sheet.html>` — 화면은 그대로 두고 문제 데이터만 바꾼다. 탭 이름 끝 "시험"은 떼고, 위쪽 `EXCLUDE`에 적힌 탭은 뺀다
4. 출력(추가·뺌·문제 바뀜·확인 필요)을 보고, **새로 넣은 과정이 "추가"에 있는지** 확인한다. "뺌"에 예상 밖 과정이 있거나 "확인 필요"가 있으면 올리지 말고 은주에게 보여준다
5. `Artifact` publish — `file_path` 새 HTML, `url` 위 링크. `capabilities`는 넘기지 않는다(이미지 저장 기능 유지)

빼 둔 탭(`EXCLUDE`, 2026-11-12):
- 디지털튜터 — 문제 없음
- 시니어웰니스전문가·일상돌봄매니저 — 폐강
- 이름이 겹치는 5쌍 — 은주가 숫자 붙은 탭을 쓰기로 정함(2026-11-12). 학교안전지도사5·노인심리상담사2·안전지도사2·경로당행정매니저2·병원원무행정전문가2를 넣고, 반대쪽(학교안전지도사 시험·노인심리상담사 시험·안전지도사·경로당행정매니저·병원원무행정전문가)은 뺀다. 화면 과정명은 끝 숫자를 뗀 이름

## 8. 마무리
1. 만든 파일 전문과 시트에 들어간 줄(추가/수정, 몇 행), 교재 발송 템플릿 결과(added/exists/skipped), 자격증관리 시트 두 탭 결과(몇 행)를 보여준다
2. 채널톡 두 채널 게시 결과(스페이스 이름·ID)와 보드 카드(검토 대기에 들어감, 등록일)를 알린다. 기출문제 답안지 갱신 결과(과정 몇 개, 새 과정이 들어갔는지)도 한 줄로 알린다
3. 은주가 검토해야 할 항목을 짚는다 (추론한 주요 업무 / 넣은 특이사항 / 비어 있는 값 / 나중에 채울 URL / 발급과정 코드번호 / 보드 카드 공개 체크·등록일)
4. "GitHub에 올릴까요?"라고 묻는다(CLAUDE.md Git 규칙)
