# 자격증 상세 문서 추가 스킬

케어아카데미에 신규 과정이 생기면 `cs-triage/ALF_docs/자격증상세/{자격증명}_{급수}.md`를 만들고, **같은 내용을 [자격증 상세 시트](https://docs.google.com/spreadsheets/d/1jXPEfaol5hhIklzjTa8INudskEnVvKo9urHr7vO9MSg/edit?gid=0)에도 한 줄 추가한다.** 교안링크가 있으면 [발송 도구 템플릿 시트](https://docs.google.com/spreadsheets/d/1CE4RQ2MKPsyA4hGHBT-p8TPCDK8D5VqfmVbc5mFOgFs/edit?gid=0)에 교재 발송 문자 템플릿도 자동으로 생긴다.
이 폴더는 **ALF 봇이 "이 자격증 따면 무슨 일 해요 / 어디서 써요 / 강의 어디서 들어요" 문의에 답할 때 쓰는 사실 잣대**다. 여기 없으면 봇이 답을 못 한다.

## 먼저 확인된 것 (다시 조사하지 말 것)
- **저장소 안에는 자격증 마스터 목록 파일이 없다.** 각 md가 독립이라 저장소에서는 **새 파일 하나만 추가하면 끝**이다. 다른 문서를 같이 고칠 필요 없음. (저장소 밖 목록은 위 시트 — 4단계에서 자동으로 채운다)
- 상위 `ALF_docs/*.md`(수강·시험·발급 정책)에는 과목별 강의 수가 하드코딩돼 있지 않다. 건드리지 말 것.

## 1. 정보 받기
아래를 물어본다. **없으면 없는 대로 진행한다.** 다 모일 때까지 기다리지 않는다.

필수 (찾아낼 수 없는 값):
1. 발급 기관 — 보통 `한국엔씨에스자격개발원(주)` 또는 `한국검정평가원`
2. 등록번호 — `2024-002000` 형식
3. 강의 개수 — `18강`
4. 강의 시간 — `40시간` 또는 `1시간 30분` 형식. 시트에만 들어간다 (md에는 안 씀). **이수증 발급 화면(`cert/`)이 이 칸을 읽어 이수증에 찍으니** 숫자만(`40`)이나 다른 표기로 쓰지 말 것
5. 강의 상세페이지 URL — `https://www.carepartner.kr/academy/○○`
6. 교육자료 PDF — 구글드라이브 링크

선택:
7. 자격증 소개 문구 / 커리큘럼 — 주면 그대로 다듬어 쓰고, 없으면 기존 파일(`실버인지활동지도사_1급.md`, `시니어웰니스전문가_1급.md`) 톤으로 초안을 쓴다
8. 활용 분야 목록
9. 특이사항 — 이름이 비슷한 국가자격 등 혼동 포인트가 있을 때만

## 2. 파일 쓰기 (템플릿)

```markdown
# {자격증명} {급수} 자격증 상세

## 1. 기본 정보
- 자격증명: {자격증명}
- 급수: {급수}
- 발급 기관: {기관}
- 등록번호: {등록번호}
- 강의 개수: {N}강

## 2. 자격증 소개
{2~3문장. "○○는 ~하는 ~ 전문인력입니다." 형태로 끝맺는다.}

## 3. 주요 업무
- {3개 내외}

## 4. 활용 분야
- {기관·시설명 한 줄에 하나}

## 5. 강의 상세페이지
- 강의 상세 페이지에서는 자격증 과정 소개 및 수강에 대한 상세 내용을 확인할 수 있습니다.
- {자격증명} 상세 페이지: {URL}

## 6. 교육자료
- {자격증명} 교육자료(PDF): {드라이브 링크}
```

## 3. 지킬 규칙
- **파일명은 `{자격증명}_{급수}.md`** — 공백 없음. 예: `실버케어지도사_1급.md`
- **섹션 번호는 유동적이다.** 특이사항이 있으면 `## 5. 특이사항`을 끼워 넣고 상세페이지·교육자료를 6·7로 민다. 없으면 위 템플릿 그대로 5·6.
- **드라이브 링크는 `?usp=sharing`을 떼고 `/view`로 끝낸다.** 기존 파일 전부 그 형식이다.
- **상세페이지가 아직 없으면** 5번을 `- 강의 상세 페이지는 아직 오픈 전입니다.` 한 줄로 대체한다. 섹션을 통째로 빼지 말 것 — 나중에 URL만 채우면 되게 자리를 남긴다.
- **주요 업무를 소개 문구에서 뽑아냈으면 반드시 알린다.** 커리큘럼을 못 받고 추론한 것이므로 은주가 실제 강의 내용과 대조해야 한다.
- **없는 정보를 지어내지 않는다.** 등록번호·강의 수를 추측하면 봇이 고객에게 틀린 사실을 말한다. 모르면 비워두고 뭐가 비었는지 보고한다.

## 4. 시트에 추가
md 파일을 만든 뒤 바로 보낸다. 은주에게 따로 묻지 않는다 (이 단계까지가 스킬의 일).

```bash
python3 .claude/skills/cert-detail/send_to_sheet.py '{"name":"{자격증명} {급수}","org":"{기관}","lectures":"{N}강","hours":"{강의 시간}","detailUrl":"{URL}","pdfUrl":"{드라이브 링크}"}'
```

- **과정명은 띄어 쓴다** — `실버케어지도사 1급` (파일명과 달리 `_` 없음). 시트는 이 값으로 같은 과정인지 찾고, **이수증 화면이 이 이름을 그대로 과정명으로 찍는다.**
- **모르는 값은 빈 문자열 `""`로 보낸다.** 상세페이지가 오픈 전이면 `detailUrl`은 `""` — "오픈 전" 같은 문구를 넣지 말 것.
- **같은 과정명이 이미 있으면 새 줄 대신 그 줄을 고친다.** 빈 값은 기존 칸을 지우지 않으니, 나중에 URL만 생겼을 때 `{"name":"...","detailUrl":"..."}`만 보내면 된다.
- 교안링크는 md와 같은 `/view` 형식으로 보낸다.
- 응답의 `values`가 실제로 시트에 들어간 값이다. 보낸 값과 다르면 은주에게 알린다.
- **응답의 `template`은 교재 발송 문자 템플릿 결과다** (웹앱이 과정 줄을 쓴 뒤 발송 도구 템플릿 시트에 알아서 만든다. 스킬이 따로 보낼 것 없음)
  - key `book_{과정명 띄어쓰기 뺀 것}`, 템플릿명 `교재 발송 ({과정명})`, 구분 문자, 본문 끝 `교재 링크:` 다음 줄에 교안링크
  - `added` = 새로 만듦 / `exists` = 같은 key가 이미 있어 **손대지 않음** (발송 도구에서 고친 문구 보호. 문구·링크를 바꾸려면 발송 도구 템플릿 관리 탭에서) / `skipped` = 교안링크가 없어 아직 안 만듦 → 나중에 `{"name":"...","pdfUrl":"..."}`만 보내면 그때 만들어짐
  - `template.ok`가 false여도 과정 줄은 이미 들어간 것이다. 템플릿 오류 문구만 은주에게 보여준다. 권한 오류면 `authorize` 재실행
- **실패하면 md 파일은 그대로 두고** 오류 문구를 보여준 뒤, 시트에 붙일 한 줄(탭으로 구분)을 `pbcopy`로 복사해 두고 은주에게 빈 줄 A칸에 ⌘V를 부탁한다. `JSON이 아닌 응답`이면 대부분 권한이 풀린 것 — 스크립트 편집기(`gas-cert-detail/` 에서 `clasp open-script`)에서 `authorize` 실행 후 허용.

## 5. 마무리
1. 만든 파일 전문과 시트에 들어간 줄(추가/수정, 몇 행), 교재 발송 템플릿 결과(added/exists/skipped)를 보여준다
2. 은주가 검토해야 할 항목을 짚는다 (추론한 주요 업무 / 비어 있는 값 / 나중에 채울 URL)
3. `GitHub에 push할까요? (cspush)` 라고 묻는다
