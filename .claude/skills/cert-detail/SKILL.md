# 자격증 상세 문서 추가 스킬

케어아카데미에 신규 과정이 생기면 `cs-triage/ALF_docs/자격증상세/{자격증명}_{급수}.md`를 만든다.
이 폴더는 **ALF 봇이 "이 자격증 따면 무슨 일 해요 / 어디서 써요 / 강의 어디서 들어요" 문의에 답할 때 쓰는 사실 잣대**다. 여기 없으면 봇이 답을 못 한다.

## 먼저 확인된 것 (다시 조사하지 말 것)
- **자격증 마스터 목록 파일은 없다.** 각 md가 독립이라 **새 파일 하나만 추가하면 끝**이다. 다른 문서를 같이 고칠 필요 없음.
- 상위 `ALF_docs/*.md`(수강·시험·발급 정책)에는 과목별 강의 수가 하드코딩돼 있지 않다. 건드리지 말 것.

## 1. 정보 받기
아래를 물어본다. **없으면 없는 대로 진행한다.** 다 모일 때까지 기다리지 않는다.

필수 (찾아낼 수 없는 값):
1. 발급 기관 — 보통 `한국엔씨에스자격개발원(주)` 또는 `한국검정평가원`
2. 등록번호 — `2024-002000` 형식
3. 강의 개수 — `18강`
4. 강의 상세페이지 URL — `https://www.carepartner.kr/academy/○○`
5. 교육자료 PDF — 구글드라이브 링크

선택:
6. 자격증 소개 문구 / 커리큘럼 — 주면 그대로 다듬어 쓰고, 없으면 기존 파일(`실버인지활동지도사_1급.md`, `시니어웰니스전문가_1급.md`) 톤으로 초안을 쓴다
7. 활용 분야 목록
8. 특이사항 — 이름이 비슷한 국가자격 등 혼동 포인트가 있을 때만

## 2. 파일 쓰기 (템플릿)

```markdown
# {자격증명} {급수} 자격증 상세

## 1. 기본 정보
- 자격증명: {자격증명}
- 급수: {급수}
- 발급 기관: {기관}
- 등록번호: {등록번호}
- 강의 개수: {N}강

## 2. 자격증 소개
{2~3문장. "○○는 ~하는 ~ 전문인력입니다." 형태로 끝맺는다.}

## 3. 주요 업무
- {3개 내외}

## 4. 활용 분야
- {기관·시설명 한 줄에 하나}

## 5. 강의 상세페이지
- 강의 상세 페이지에서는 자격증 과정 소개 및 수강에 대한 상세 내용을 확인할 수 있습니다.
- {자격증명} 상세 페이지: {URL}

## 6. 교육자료
- {자격증명} 교육자료(PDF): {드라이브 링크}
```

## 3. 지킬 규칙
- **파일명은 `{자격증명}_{급수}.md`** — 공백 없음. 예: `실버케어지도사_1급.md`
- **섹션 번호는 유동적이다.** 특이사항이 있으면 `## 5. 특이사항`을 끼워 넣고 상세페이지·교육자료를 6·7로 민다. 없으면 위 템플릿 그대로 5·6.
- **드라이브 링크는 `?usp=sharing`을 떼고 `/view`로 끝낸다.** 기존 파일 전부 그 형식이다.
- **상세페이지가 아직 없으면** 5번을 `- 강의 상세 페이지는 아직 오픈 전입니다.` 한 줄로 대체한다. 섹션을 통째로 빼지 말 것 — 나중에 URL만 채우면 되게 자리를 남긴다.
- **주요 업무를 소개 문구에서 뽑아냈으면 반드시 알린다.** 커리큘럼을 못 받고 추론한 것이므로 은주가 실제 강의 내용과 대조해야 한다.
- **없는 정보를 지어내지 않는다.** 등록번호·강의 수를 추측하면 봇이 고객에게 틀린 사실을 말한다. 모르면 비워두고 뭐가 비었는지 보고한다.

## 4. 마무리
1. 만든 파일 전문을 보여준다
2. 은주가 검토해야 할 항목을 짚는다 (추론한 주요 업무 / 비어 있는 값 / 나중에 채울 URL)
3. `GitHub에 push할까요? (cspush)` 라고 묻는다
