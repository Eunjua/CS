> 🔀 **아카데미 채널 export만 누적한다.** 케어파트너 채널(16차~)은 이 엑셀에 넣지 않는다 — 전화·케어파트너 문의가 섞여 기준표 분포가 흐려진다([sources.md](sources.md) 「채널 구분」).

시트명은 유니코드 정규화(NFC/NFD) 차이가 있을 수 있으니 `unicodedata.normalize('NFC', s)`로 매칭해 찾는다. 시트명이 바뀌어 있으면 그 시트를 쓴다.
openpyxl로 append 전 **원본을 한 번 백업**(스크래치패드 복사)하고 저장한다. 기존 행은 보존(append-only).

## 4. `분석` 시트에 건별로 이어 붙인다

판정한 배치를 건별로 **`분석` 시트**(구 `이관사유_상세`, 같은 시트)에 이어 붙인다.

| 열 | 내용 |
|---|---|
| A 순번 | 기존 마지막 순번 이어서 |
| B id · C url · D 태그(원본) | UserChat 시트에서 (measure.py가 만든 건별 CSV에 다 있다) |
| E 분류태그 | 원본 `아카데미_` 태그에서 접두어 제거, 없으면 빈칸 |
| F 5단계 분류 | ①/②-A/②-B/③실작업/③감정/③기술, **ALF 미발동은 `제외`** |
| G 이관 사유 | 한 줄 |
| **H** | 🚫 **절대 건드리지 않는다** — 은주 수기 확인용, 항상 공백으로 남김 |
| I 없앨수있는이관 | ②=Y / ③=N / ①·제외=`-` |

- id·url·태그·`alfTriggered`·**배정 3칸**은 전부 UserChat 시트에서 뽑는다(Message data 불필요). F·G·I는 판정 결과를 쓴다.
- **ALF 미발동 건도 행은 남긴다**(추적용). 단 F열에 `제외`, G열에 "ALF 미발동(alfTriggered=false)"이라 적고 **집계시트에는 넣지 않는다.**

## 4-1. 유형별 집계시트에 일자별 건수 추가

같은 엑셀의 **6개 집계시트**(`집계_①현재AI` · `집계_②A즉시자동화` · `집계_②B시스템연동` · `집계_③실작업` · `집계_③감정전화` · `집계_③기술오류`)에 새 상담을 **상담 날짜(createdAt)별 열**로 이어 붙인다(열 헤더 예 `06-22`). 여러 export 파일을 함께 받으면 **id로 중복 제거(union)** 후 날짜 집계한다(measure.py가 union까지 해 준다). 배치에 섞인 아주 오래된 소량 날짜는 `~MM-DD` 한 열로 묶어도 된다.

- **건별 실제 판정으로 배정**: 봇완결(상담원 미배정)=`①현재AI` / 이관건은 세부태그의 대분류로. 그래서 **같은 세부태그(예 일자리)가 완결분은 ①시트, 이관분은 ②-A시트에 각각** 나뉘어 들어간다.
- **🚫 ALF 미발동 건(`alfTriggered=false`)은 6개 시트 어디에도 넣지 않는다.** 상담원 발화가 있다고 이관으로 세면 안 된다 — 봇이 등장할 기회조차 없던 건이다.
- **`AI상담/고객이탈` 태그 건도 미배정이면 `①현재AI`에 넣는다**(2026-09-07 변경, 이전엔 뺐다). 이탈은 시트에서 빼는 대신 **별도 이탈률로 따로 세어** 종합에 "이탈률 x%(N건)"으로 완결률 옆에 밝힌다.
- **검증식**: `6개 시트 합 + ❌놓침 = alfTriggered=true 건수`, 그리고 `alf발동 + 미발동 = 총 상담수`. 두 식이 모두 맞아야 저장한다(뒤쪽 식은 measure.py가 매번 확인해 준다).
- **세부태그→대분류 매핑**: `분석` 시트에서 학습(각 태그의 ① 제외 이관 최빈 대분류)한다. 명백한 기술장애(`수강/동영상`·"소리/영상 안 나옴") = ③기술오류, 감정·전화고집 발화 = ③감정전화로 보정. 봇 발화 없으면 이 세분은 근사임을 밝힌다.
- 각 시트: **A열 유형(세부태그)** · **B열~ 일자별 건수**(최신 날짜 건수 내림차순 정렬) · 맨 아래 **합계행**. **새 유형은 해당 시트 맨 아래 새 행**으로 추가.
- **`요약` 시트도 같이 갱신**: 6대분류 × 일자별 전체 건수 표. `버킷 | 액션 | 기준선(05~06) | [일자 열들...]` 구조로, 각 집계시트 합계행 값을 일자 열에 이어 붙이고 맨 아래 합계행을 갱신한다(집계시트 합과 일치).
