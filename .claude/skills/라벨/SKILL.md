# 라벨 규격 맞추기

은주가 준 파일이나 글을 라벨지 칸에 딱 맞게 옮겨 **A4 인쇄용 PDF**로 만든다. 도구는 이 폴더의 `relabel.py` 하나.

```bash
python3 .claude/skills/라벨/relabel.py specs        # 등록된 규격 보기
```

## 0. 규격 정하기
- 말이 없으면 **LS-3108**(폼텍 주소용 14칸, 2열×7줄, 칸 99.1×38.1mm).
- 다른 라벨지를 말하면 `relabel.py`의 `SPECS`에 있는지 본다. **없으면 짐작해서 만들지 않는다.** 상자 뒷면·제조사 표기에서 칸 수·칸 크기·여백을 확인받아 한 줄 추가한 뒤 진행한다(검색 결과의 치수는 판매처마다 틀릴 수 있음 — 2026-11-19 LS-3108도 상품명엔 칸 수만 있었다).

## 1. 무엇을 받았는지에 따라

| 받은 것 | 방법 |
|---|---|
| 원본 PDF (우체국 등기 라벨 등) | `pdf` — 내용은 원본 그대로(벡터, 바코드 선명), 칸 위치만 옮긴다 |
| 원본 PDF + "이것만" (캡처·번호·이름) | `pdf --pick` — 고른 라벨만, 준 순서대로 |
| 캡처 이미지만 | **먼저 "원본 PDF 있어요?" 묻는다.** 없을 때만 `image` |
| 글만 (보내는 곳 주소 등) | `text` — 모든 칸에 같은 내용 |

### PDF
```bash
python3 .claude/skills/라벨/relabel.py pdf ~/Downloads/원본.pdf
python3 .claude/skills/라벨/relabel.py pdf ~/Downloads/원본.pdf --pick 7360,7367,7361 --out 등기라벨_19장_LS-3108.pdf
```
- 칸마다 한 번씩 나오는 글자(기본 `귀하`)로 원본 칸을 찾고, 원본 칸 간격을 자동으로 잰다. 다른 형식이면 `--anchor`로 그 글자를 준다.
- **"이것만 해줘"가 오면 꼭 `--pick`.** 캡처를 받으면 캡처 속 등기번호 끝 4자리를 **캡처에 보이는 순서대로**(캡처 안에서는 위→아래, 한 줄은 왼→오) 적어 넘긴다. 없는 번호·여러 건 걸리는 번호는 스크립트가 멈추고 알려준다.
  - 2026-11-19: 원본 6쪽(71장)을 다 옮겼다가 "캡처로 보내준 것만!"이라는 말을 들었다. 캡처와 PDF를 같이 받으면 **캡처에 있는 것만**이 기본이다. 애매하면 묻는다.
- 결과는 `~/Downloads/`에 저장(기본 이름 `원본이름_LS-3108.pdf`).

### 캡처 이미지 (원본 PDF가 없을 때만)
```bash
python3 .claude/skills/라벨/relabel.py image 캡처1.png 캡처2.png --out 등기라벨_캡처_LS-3108.pdf
```
- 빈 줄 기준으로 라벨 한 장씩 잘라 칸에 넣는다. 붙여 넣은 이미지는 세션 폴더 `images/`에 있다.
- 출력되는 장수가 캡처 속 라벨 수와 다르면 `--gap`(라벨 사이 빈 줄 px, 기본 30)을 바꿔 다시.
- **바코드가 화면 캡처 해상도라 우체국에서 안 읽힐 수 있다**고 꼭 알린다.

### 글만
```bash
python3 .claude/skills/라벨/relabel.py text --line "케어아카데미" --line "주소  서울특별시 강남구 역삼동 641-10, 아승빌딩 2층" --line "연락처  1588-5877" --out 케어아카데미_라벨_LS-3108.pdf
```
- 첫 줄은 굵게, 나머지는 작게. 기본 한 장(14칸) 가득, `--count`로 장수 조절.

## 2. 확인하고 보내기 (매번)
1. **칸 미리보기**: `relabel.py preview 결과.pdf` → 쪽마다 빨간 점선 칸이 그려진 PNG가 나온다. Read로 열어 **글·바코드가 칸 밖으로 잘린 곳이 없는지** 본다(테두리는 미리보기에만, 결과 PDF엔 없음).
2. **개수 대조**: 원본(또는 캡처)의 라벨 수·등기번호와 결과가 같은지. `pdf` 모드는 장수와 라벨별 첫 글자를 출력하니 그걸로 대조한다.
3. `SendUserFile`로 결과 PDF를 보낸다.
4. 답에 꼭 넣을 것:
   - 몇 장 → 몇 쪽(한 쪽 14칸, 마지막 쪽 빈 칸 몇 개). "한 페이지로"라고 해도 14장 넘으면 2쪽이 될 수밖에 없다고 먼저 말한다.
   - 인쇄 배율은 **「실제 크기(100%)」** ("페이지에 맞추기"면 칸이 어긋남).
   - 실제 라벨지에 맞는지는 확인 못 했으니, 일반 A4에 한 장 먼저 뽑아 라벨지 뒤에 대 보라고.

## 지킬 것
- 고객 주소가 든 파일이라 **결과는 `~/Downloads/`(또는 세션 임시 폴더)에만**. CS 저장소(공개)에 넣거나 커밋하지 않는다. 이 문서에도 실제 고객 주소 예시는 적지 않는다.
- 은주가 준 원본 파일은 고치거나 지우지 않는다. 결과는 항상 새 파일.
