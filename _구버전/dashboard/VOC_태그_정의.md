# VOC 태그 정의

## 1. 태그 구성 요소

VOC는 아래 2가지 태그를 기준으로 분류합니다.

1. **이슈**: 왜 문제가 되었는가 (문제의 성격)
2. **코어 태그(Core_기능)**: 서비스 이용 과정 중 어디에서 문제가 발생했는가

### 태그 구조

코어 태그는 아래와 같은 계층 구조로 표기합니다.

```
대분류_중분류/소분류
```

| 계층 | 명칭 | 설명 | 예시 |
|------|------|------|------|
| 대분류 | 서비스 | 문의가 발생한 서비스 영역 | `요`, `기관`, `아카데미` |
| 중분류 | 코어(Core) | 서비스 이용의 큰 단계/영역 | `결제`, `수강`, `자격증` |
| 소분류 | 기능 | 고객이 실제로 막힌 구체적인 지점 | `결제방법`, `발급과정`, `배송` |

**표기 예시**

- `아카데미_결제/결제방법`
- `아카데미_자격증/발급과정`
- `기관_기관_결제/결제실패`
- `요_구직/일자리 상세`

---

## 2. 이슈 태그 정의

이슈 태그는 **문제의 성격**을 나타내는 태그입니다.

> **이슈 판단 플로우**
> 1. 기능이 실제로 작동하지 않나? → YES면 **오류**
> 2. 새 기능 요청? → **제안**
> 3. 그 외 → 이슈 태그 부착 X

### 오류

- 기능이 정상적으로 동작하지 않는 경우
- 예: 버튼 클릭 불가, 결제 실패, 화면 오류

### 제안

- 현재 문제라기보다 개선 아이디어나 기능 제안
- 현재 제공하지 않는 기능
- 예: 이력서 수정하고 싶어요, 회원 탈퇴 하고 싶어요, 자격증 한번에 결제하고 싶어요

---

## 3. 코어 태그(Core_기능) 정의

코어 태그란, 고객 문의가 발생한 서비스 이용 과정에서 **'어느 영역(Core)의 어떤 지점(기능)에서 문제가 발생했는지'** 를 나타내는 태그입니다.

- **Core**: 서비스 이용의 큰 단계/영역
- **기능**: 그 안에서 고객이 실제로 막힌 구체적인 지점

코어 태그는 **여러 개 선택 가능**하나, 아래 규칙을 따른다.

---

## 4. 코어 태그 선택 규칙

### ✅ 여러 코어 선택 가능한 경우

- 고객이 명시적으로 여러 기능을 언급
- 한 문의에서 순차적으로 다른 문제를 겪음
  - 예: "가입하려다 안 되서 문의했는데, 이왕이면 공고 등록 방법도 알려주세요" → **회원가입 + 공고등록**

### ❌ 여러 코어 선택하지 말아야 할 경우

- 한 기능의 부작용으로 다른 문제가 생긴 것
  - 예: "배송지 입력이 안 돼서 결제가 진행 안 됨" → **발급과정만**
- 원인과 결과가 명확한 경우, **원인이 되는 기능만** 선택
