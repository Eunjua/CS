# 민간자격 등록신청 서류 검토 체크리스트

> 작성 기준: 2025_ver.1.2 민간자격 등록신청 편람(매뉴얼), 한국직업능력연구원

---

## 1. 구비서류 완비 여부

### [회원가입 단계]
- [ ] 사업자등록증 (또는 고유번호증) 1부
- [ ] 법인: 법인등기부등본 1부 / 개인·단체(미등기): 대표자 주민등록초본 1부
  - ※ 주민등록번호 뒷자리 6자리 삭제 후 업로드 여부 확인
- [ ] 검정시설·장비를 포함한 재산목록 및 권리관계 증명서류 1부
  - 소유: 부동산등기부등본
  - 임대: 임대차계약서
  - 무상사용: 장소 사용에 관한 당사자 간 협약서

### [등록신청 단계]
- [ ] (법인기관만 해당) 민간자격관리자 결격사유확인서 1부
  - ※ 법인등기부등본 상 대표자 외 **모든 등기 임원** 작성 필요
- [ ] 민간자격관리·운영규정 1부
- [ ] (해당 자격만 제출) 교육과정 운영 인가·등록·신고 증빙서류 1부

---

## 2. 홈페이지 입력 내용 ↔ 제출서류 일치 여부

- [ ] 회원가입 시 입력한 **기관명**이 사업자등록증과 일치하는지 확인
- [ ] **사업자등록번호**, **법인등록번호** 일치 여부 확인
- [ ] **대표자 성명** 일치 여부 확인
- [ ] **자격명, 등급명, 직무내용, 검정기준, 검정방법, 검정과목, 응시자격, 응시자 본인확인 방법**이 관리·운영규정 내용과 일치하는지 확인
  - ※ 규정 해당 페이지 번호 및 조항 번호까지 입력 필요
- [ ] 여러 자격을 종목별로 **각각 별도 신청**했는지 확인 (복수 기재 시 접수 불가)

---

## 3. 민간자격관리·운영규정 필수 항목

아래 항목이 규정에 모두 포함되어 있는지 확인:

- [ ] 자격의 종목 및 등급
- [ ] 자격의 직무내용
- [ ] 검정기준
- [ ] 검정과목
- [ ] 검정방법
- [ ] 응시자격
- [ ] 자격의 검정에 필요한 인력 현황
- [ ] 자격의 관리·운영조직에 관한 사항
- [ ] 자격검정 시 응시자 본인 확인에 관한 사항

> ※ 위 항목 누락 또는 홈페이지 입력 내용과 불일치 시 **접수 불가**

---

## 4. 자격 내용 작성 시 주의사항

- [ ] **직무내용**: 자격취득자가 수행하는 업무를 명확하고 구체적으로 작성 (한글 200자 이내)
  - ※ 불명확하거나 모호한 경우 처리 지연·반려 가능
- [ ] **주무부처 선택**: 해당 민간자격의 소관 부처를 정확히 선택했는지 확인
  - ※ 잘못 선택 시 타 부처로 이송 → 검토 기간 수개월 추가 지연
- [ ] **자격명칭**: 국가자격 또는 공인자격과 동일한 명칭 사용 불가, 사전 확인 필수
  - ※ 홈페이지 내 "국가/공인 자격 명칭 동일여부 확인" 버튼으로 검토
- [ ] 자격등급명이 30개 이하인지 확인 (30개 초과 시 별도 문의 필요)
- [ ] 관계 중앙행정기관과 주무부장관(필수)이 **중복 선택**되지 않았는지 확인

---

## 5. 대표자 정보 정확성

- [ ] 대표자 **등록기준지(구 본적지)** 정확히 입력 여부 확인
  - ※ 오류 3회 초과 시 등록신청 반려
- [ ] 대표자 **주민등록번호** 정확히 입력 여부 확인
  - ※ 결격사유조회 시 오류 발생하면 반려 가능
- [ ] 결격사유확인서 상 임원 목록과 법인등기부등본 상 임원 **일치 여부** 확인
  - ※ 불일치 시 접수 불가
  - ※ 임원 중 미성년자 등 결격사유 해당자 포함 시 등록 불가

---

## 6. 신청 기간 및 절차

- [ ] 신청일이 **매월 1일~20일** 이내인지 확인 (21일~말일은 신청 불가)
- [ ] **공동인증서 로그인**으로 신청했는지 확인 (아이디 로그인으로는 신규등록 신청 불가)
- [ ] "신규등록 신청하기" 클릭 전 모든 내용 충분히 검토 완료
  - ※ 클릭 이후 신청내용 **수정 불가**
- [ ] 서류보완 요청 시 수정 후 **"서류보완완료" 버튼 클릭** 여부 확인
  - ※ 버튼 클릭하지 않으면 접수 불가

---

## 7. 파일 업로드 시 주의

- [ ] 파일 용량 **10MB 미만**인지 확인 (초과 시 업로드 제한)
- [ ] 지원 형식 확인: **JPG, GIF, BMP, PDF, JPEG** (그림파일) / **HWP, PDF** (문서파일)
- [ ] PDF 파일의 경우 이미지 상 글씨가 **드래그(복사)되지 않는** 파일인지 확인
  - ※ 드래그 가능한 PDF는 업로드 제한됨
- [ ] 주민등록초본: **주민등록번호 뒷자리 6자리 삭제** 후 업로드 여부 확인

---

## 8. 민간자격관리·운영규정 문서 품질 검토

> 제출 규정 문서 자체의 내용·표현 검토 항목

- [ ] **법적 표현의 명확성 및 적절성** — 조항 문구가 법적으로 명확한지
- [ ] **규정 내용의 완결성** — 빠진 조항이 없는지
- [ ] **한국어 문장의 자연스러움** — 어색한 표현이 없는지
- [ ] **민간자격 운영규정으로서의 타당성** — 민간자격 등록 기준에 부합하는지

---

## 9. 추가 검토 조건 제안

### ✅ 등록 가능 여부 사전 검토
- [ ] **금지분야 해당 여부** 사전 확인
  - 다른 법령에서 금지하는 행위 관련 분야
  - 국민 생명·건강·안전 및 국방에 직결되는 분야
  - 선량한 풍속을 해하거나 사회질서에 반하는 분야
  - ※ 주무부처별 '민간자격 신설 금지분야 세부사항 공고' 게시판 사전 확인
- [ ] **자격명칭 금지 여부** 확인
  - ※ 「자격기본법」 제14조 및 관계 법령상 명칭사용 금지대상 해당 여부

### ✅ 결격사유 사전 검토
- [ ] 법인 대표자 및 등기임원 전원에 대한 결격사유 사전 검토
  - 미성년자·피성년후견인·피한정후견인
  - 파산선고를 받고 복권되지 아니한 자
  - 금고 이상의 실형 선고 후 집행 종료/면제 후 3년 미경과자 등
- [ ] 결격사유확인서 서명·날인 누락 여부 확인

### ✅ 등록면허세 납부 준비
- [ ] 사업장 소재지 관할 지자체 세율 확인
  - 인구 50만 이상의 시: 40,500원
  - 그 밖의 시: 22,500원
  - 군: 12,000원
- [ ] 납부확인서에 **자격명 또는 등록번호 기재** 여부 확인 필수
- [ ] 납부확인서 제출 방법 확인 (이메일 또는 팩스)

### ✅ 공동발급기관 관련 확인
- [ ] 공동발급으로 등록 후 단일명의로 변경 불가 여부 사전 검토
  - ※ 단일명의 필요 시 별도 신규등록 필요
- [ ] 공동발급기관의 민간자격정보서비스 **별도 회원가입** 완료 여부 확인

### ✅ 교육훈련과정 인가 여부 확인
- [ ] 자격 취득 필수 교육과정을 직접 운영하는 경우, 관할 행정청에 인가·등록·신고 필요 여부 사전 확인
  - 학원법·평생교육법 관련: **시도교육지원청**
  - 수상레저안전법 관련: **해양경찰청 및 시군구**

### ✅ 인증서 확인
- [ ] 공동인증서가 **대표자 본인** 또는 (법인)신청기관 명의인지 확인
  - ※ 실무자의 공동인증서 사용 불가
