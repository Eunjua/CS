구글 스프레드시트를 연결하세요

Apps Script로 동기화된 대시보드_공개용 시트를 연결하면
자동으로 최신 데이터를 불러와요.

연결 방법

  • 구글 시트 → 파일 → 공유 → 웹에 게시 → CSV 형식으로 게시
  • 게시된 URL을 복사해서 위 버튼을 눌러 붙여넣기
  • 연결 후 매일 자동 동기화 (Apps Script 트리거)
  • 헤더의 🔄 새로고침으로 수동 동기화 가능
