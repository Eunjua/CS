## Goal
신입 CS 상담원이 **혼자 따라가며 케이스별 응대를 학습**할 수 있도록, 고객의 답변·상태에 따라 갈리는 응대를 **클릭형 분기 흐름도**로 보여주는 **읽기형 교육 화면**을 만든다. 콘텐츠는 **구글시트**로 관리하고(코딩 없이 행만 추가), 화면이 시트를 읽어 흐름도를 자동으로 그린다. 화면은 VOC 대시보드와 **분리된 별도 URL**로 제공한다.

**범위: 1차는 케어아카데미 전용.** 왼쪽 케이스 목록은 아카데미의 **중분류(수강 / 자격증 / 결제)** 기준 **접이식 그룹**으로 묶는다. (다른 서비스 — 기관/요양/일반 — 는 1차 범위 밖.)

## Constraints
- 유지보수는 **구글시트에서** 한다. 케이스/단계/멘트는 시트에 행으로 입력 → 화면 자동 반영. (dashboard와 동일 패턴: 시트 → GitHub Pages)
- 시트 스키마는 **풀버전**(단계ID·부모단계·분기조건 포함)으로 간다. 단순 "상태→응대" 버전보다 표는 복잡하지만, 깊은 분기도 막힘없이 표현 가능 → 장기 운영 우선.
- **화면 안 편집 없음.** (저장 서버·로그인·권한·편집기 UI를 새로 만드는 비용/유지보수 부담이 크기 때문. GitHub Pages는 읽기 전용.)
- 화면 위치: **VOC 대시보드와 분리된 별도 URL.**
- 1차 범위: **케어아카데미 주요 케이스 10개+** 를 풀빌드.
- 케이스마다 **분류(중분류: 수강/자격증/결제)** 를 가지며, 왼쪽 목록은 이 분류 기준 **접이식 그룹**으로 표시 (케이스가 늘어도 목록이 길어지지 않게). 분류는 기존 VOC 태그 체계(아카데미 하위)를 재활용.
- 1차는 **읽기형**만. 퀴즈/연습은 제외(v2).
- 비개발자가 운영 → 시트 입력 규칙은 최대한 단순하게(새로 배울 개념은 "단계ID/부모단계" 두 칸 수준).
- 한국어 화면, 주 사용자: 신입 CS 상담원.

## Non-Goals
- 케어아카데미 외 서비스(기관/요양/일반) 케이스 (1차 범위 밖, 추후 확장)
- 실시간 상담 중 빠른 검색/참고 최적화 (1순위 아님)
- 퀴즈·정답 확인 등 능동학습 기능 (v2)
- 화면 내 콘텐츠 편집(인앱 에디터), 로그인·권한 시스템
- VOC 대시보드와의 통합/탭 추가
- 검색창·고급 필터

## Acceptance Criteria
- [ ] 구글시트에 케이스를 행으로 입력하면(단계ID·부모단계·분기조건·유형·내용·참고링크), 화면에 분기 흐름도로 자동 렌더링된다.
- [ ] "입금 확인" 케이스가 흐름도로 정확히 표현된다: 질문 → 어드민 조회(참고링크 포함) → 입금됨/미입금 분기 → 미입금 시 "고객 요청 시 계좌 안내" 곁가지.
- [ ] 주요 케이스 **10개 이상**이 들어간 상태로 1차 공개된다.
- [ ] 신입 상담원이 케이스 목록(주제별)에서 원하는 케이스를 골라, 흐름도를 읽으며 "이 상태면 이렇게 응대한다"를 스스로 이해할 수 있다.
- [ ] 화면은 VOC 대시보드와 분리된 **별도 URL**로 열린다.
- [ ] 케이스 추가 시 코드 수정 없이 **시트 행 추가만**으로 반영된다.
- [ ] 참고링크(어드민 URL 등)는 클릭 가능한 바로가기로 표시된다.

  - **기존 응대 스크립트/FAQ는 없음** → 콘텐츠(분기 응대)는 새로 정리하는 게 핵심 일감.
- 신규 산출물:
  - 케이스 데이터용 **구글시트**(스키마: 분류 / 케이스 / 케이스설명 / 단계ID / 부모단계 / 분기조건 / 유형(질문·조회·안내) / 내용 / 참고링크).
  - 시트를 읽어 **분기 흐름도로 렌더링하는 별도 웹페이지**(별도 URL, GitHub Pages 또는 유사 정적 호스팅).

## 구현 현황 (2026-06-12, v0 시제품)
- `cs-guide/index.html` — 분기 흐름도 화면. 왼쪽은 **분류(중분류)별 접이식 그룹**, 가운데는 클릭형 흐름도(질문/조회/안내 + 갈래 펼치기/접기), 아래는 원본 시트 미리보기. 시트 미연결 시 샘플 '입금확인'으로 폴백.
- `gas/CSGuide.gs` — GAS 웹앱. **doGet**(시트→화면 JSON 읽기) + **doPost**(케이스 JSON을 받아 시트에 upsert/delete 쓰기). 간단 비밀키(`WRITE_TOKEN`)로 무단 쓰기 차단. `seedData()`는 일회성 초기 채움용(운영 중 사용 금지).
- 동작 흐름(완성): **사용자가 말로 설명 → (Claude가) doPost로 시트에 기록 → 화면이 doGet으로 읽어 흐름도 표시.** 시트/GAS를 사람이 직접 건드릴 필요 없음.
- `.claude/skills/case/SKILL.md` — `/case` 스킬. 다른 세션에서도 자연어로 케이스 추가·수정·삭제 가능(이 프로젝트 한정).
- 현재 시트 등록 케이스: 입금 확인(결제), 일자리 안내(일자리).
- 남은 일: 케이스 더 채우기(수강/자격증 실제 케이스), **GitHub Pages 배포(`cspush`)** 로 에이전트 공유, (v2) 퀴즈 모드.
