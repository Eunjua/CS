## Goal
은주가 발급 기관에 **카톡으로 제작 취소를 요청한 건**이, **정산집계 시트에는 반영되지 않아 정산(금액)에 그대로 포함되는 누락**을 막는다. 은주는 취소 건을 **1회 표시**만 하면(카톡은 도구가 못 읽으므로 이 한 번은 불가피), 그 뒤 **정산표 생성 시 취소 건을 자동으로 제외하고 금액·부가세를 재계산**한다. 즉 "입력 1번을 제외한 나머지는 자동". 추가로, 표시했지만 정산에 새어든 건이 없는지 점검도 자동으로 한다.

### 자동화 경계 (명시)
- **사람(불가피)**: 취소 건을 도구에 1회 표시 (체크박스 또는 "취소" 입력). 취소 사실은 카톡에만 있어 도구가 알 수 없으므로.
- **자동**: 정산표 생성 시 취소 건 제외 + 금액/부가세 재계산, 취소 누락 점검.

## Constraints
- 구글 스프레드시트 + Google Apps Script(GAS) 환경 안에서 만든다 (기존 `자격증발급스크립트.gs`와 같은 시트).
- 일반 카카오톡 자동발송은 기술적으로 불가능 → **발송 자동화는 범위에서 제외**. 카톡 소통은 지금처럼 사람이 직접.
- 알림톡(비즈니스 메시지)은 사용하지 않기로 결정.
- 취소 정산 규칙이 아직 확정 안 됨 → v1은 **금액 자동 조정 안 함**, 표시·경고만.
- 비개발자(은주)가 직접 쓰는 도구 → 조작은 한두 번 클릭/입력 수준으로 단순해야 함.

## Non-Goals

- 취소건 정산금액의 자동 차감 (규칙 미확정).

## Acceptance Criteria
- [ ] 정산집계(또는 제작리스트)에 제작 건을 **'취소'로 표시**할 수 있다 (체크박스 또는 "취소" 입력 + 취소일).
- [ ] **정산표 생성(`createSettlementTable`) 시 취소 건이 자동으로 제외**되고 금액·부가세가 다시 계산된다.
- [ ] 기본값은 "취소 = 정산 제외". 예외인 **"제작 후 취소(비용 남김)"** 는 별도 표시로 비용을 유지할 수 있다.
- [ ] 점검 실행 시 "취소 표시했는데 정산에 아직 포함된 건 N건" 형태로 누락을 한눈에 알려준다.
- [ ] 취소 시점(요청일)이 기록되어, '제작 전/후' 구분 및 추후 규칙 정교화가 가능하다.
- [ ] 기존 `자격증발급스크립트.gs`의 발급·배송·정산 흐름을 깨뜨리지 않는다.
