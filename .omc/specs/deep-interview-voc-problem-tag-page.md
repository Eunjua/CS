## Goal
VOC 주간 대시보드에서 **NPS 탭을 제거**하고, 그 자리에 **"문제 태그 진단" 새 탭**을 추가한다.
새 탭은 CSAT 설문 응답(매핑결과 시트)을 태그별로 집계하여 **만족도·해결율·대기불만 세 지표를 100점으로 환산·가중합한 "문제 점수"로 태그를 내림차순 순위화**한다. 문제가 가장 큰 태그가 맨 위에 떠서, 은주가 "이번 주 어디부터 개선할지"를 한눈에 판단할 수 있게 한다.

## Constraints
- **문제 점수 가중치**: 만족도 50% / 해결율 40% / 대기시간 10% (합 100%)
- **지표 정의 (모두 CSAT 설문 응답 기준, 매핑결과 시트)**:
  - 만족도 = 태그별 평균 만족도(1~5점). 낮을수록 문제.
  - 해결율 = 그 태그 상담 중 해결여부 "긍정(해결됨)" 응답 비율(%). 낮을수록 문제.
  - 대기시간 = 그 태그 상담 중 대기시간 "부정(불만)" 응답 비율(%). 높을수록 문제.
- **100점 환산식 (문제 기여도, 높을수록 문제)**:
  - 만족도 → `(5 - 평균만족도) / 4 × 100`
  - 해결율 → `100 - 해결율(%)`
  - 대기시간 → `대기 부정 응답 비율(%)` (이미 0~100)
  - 문제점수 = `만족도기여 × 0.5 + 해결율기여 × 0.4 + 대기기여 × 0.1`
- **집계 기간**: 기본은 주차 선택(1주), '최근 4주 누적' 토글 제공. 기존 주차 드롭다운 UI 패턴 재사용.
- **최소 표본 처리**: 응답 적은 태그도 순위에 포함하되 "⚠ 표본 적음(n=?)" 경고 표시 (기본 임계 n<5 — 가정, 조정 가능).
- **전주 대비 ↑↓**: 주차 선택 모드에서만 각 지표/점수의 전주 대비 악화·개선 화살표 표시 (누적 모드에선 미표시).
- 비개발자 유지보수 고려: 가중치·임계값은 코드 상단 상수로 빼서 쉽게 바꿀 수 있게.

## Technical Context (brownfield)
- 데이터 출처: `매핑결과` 시트 (`?sheet=csat` → `getSheetAsJson(ss, SHEET_MAPPED)`). 헤더: `상담ID, 상담일시, 채널, 태그, 상태, 만족도, 친절도, 해결여부, 대기시간, 자유의견, 응답일시` (`gas/VOC_통합스크립트.gs:95-98`).
- 만족도=1~5 숫자, 해결여부·대기시간=텍스트(긍/중/부정), `isNegativeAnswer_()`로 부정 판정 (`gas/VOC_통합스크립트.gs:1209-1278`).
- 태그는 쉼표 구분, 한 상담에 여러 태그 → 각 태그에 점수 귀속 (`index.html:1461-1487`, gas 1247-1255).
- 기존 CSAT 탭에 태그별 만족도 히트맵은 있으나, **해결여부·대기시간은 전역 집계(subAgg)만 존재** → 태그별 집계 신규 구현 필요.
- 탭 추가/삭제: 버튼 배열(`index.html:333-339`) + `switchTab()`(1340-1383) + 탭별 render 함수 패턴.
- 데이터 흐름: GAS doGet 웹앱 API(`?sheet=`) → GitHub Pages `index.html` fetch. 신규 페이지는 기존 csat 데이터(매핑결과)만으로 계산 가능 — **GAS 수정 없이 대시보드(index.html)만 수정해도 v1 구현 가능**할 가능성이 높음.
