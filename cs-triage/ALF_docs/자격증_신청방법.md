# 자격증 신청 방법

## 신청 시점
- **시험 합격(60점) 후** 신청 가능합니다.

## 신청 경로
- 케어파트너 앱 또는 사이트 → **내강의실 → "자격증 신청하기" 버튼**
- 내강의실: https://www.carepartner.kr/academy/my

## 배송 기간
- 신청 후 **7일 이내** 수령 가능합니다.

## 진행 순서
1. 케어파트너 앱/사이트 접속
2. 내강의실 진입
3. '자격증 신청하기' 버튼 클릭
4. 이름·생년월일(8자리)·배송지 주소 입력
   - 이름: **주민등록상 이름**으로 입력해 주세요
   - 생년월일 예시: `19661102`
5. 결제 완료
6. **7일 이내 실물 자격증 수령**

## 자격증 실습
- 케어아카데미에서 취득하는 자격증 과정에는 **실습이 포함되어 있지 않습니다.**
