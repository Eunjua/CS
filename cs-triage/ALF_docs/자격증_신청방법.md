# 자격증 신청 방법

## 신청 시점
- 시험 합격(60점) 후 신청 가능합니다.
- 자격증 신청 기한: 시험 합격 후 7일 이내에 신청·결제를 완료해야 합니다. ("원할 때 아무 때나 신청할 수 있나요?" 문의 시 → 합격일로부터 7일 이내 신청 필요로 안내합니다. 아래 '배송 기간'의 7일과는 다른 별개의 기한입니다.)

## 신청 경로
- 케어파트너 앱 또는 사이트 → 내강의실 → "자격증 신청하기" 버튼
- 내강의실: https://www.carepartner.kr/academy/my

## 배송 기간
- 신청 후 7일 이내 수령 가능합니다.
- ⚠️ 배송 현황(배송 추적) 조회 기능은 없습니다. "언제 오나요/배송 어디까지 왔나요" 문의 시 **"신청 후 7일 이내 수령"까지만 안내**하고, 내강의실·앱에서 배송현황을 확인할 수 있다고 안내하지 않습니다. 7일이 지나도 미수령이면 상담원 연결로 안내합니다.

## 진행 순서
1. 케어파트너 앱/사이트 접속
2. 내강의실 진입
3. '자격증 신청하기' 버튼 클릭
4. 이름·생년월일(8자리)·배송지 주소 입력
   - 이름: 주민등록상 이름으로 입력해 주세요
   - 생년월일 예시: `19661102`
5. 결제 완료
6. 7일 이내 실물 자격증 수령

## 결제 수단
- 카드 결제와 계좌이체 모두 가능합니다.
- 계좌이체를 선택하면 가상계좌번호가 발급됩니다. 계좌번호는 카카오톡 알림 또는 내 자격증 관리 페이지(https://www.carepartner.kr/academy/my?tab=certificates)에서 확인할 수 있습니다.
- 본인 명의가 아닌 카드·계좌로 결제해도 됩니다. (예: 자녀·가족 명의 카드/계좌 가능) — 결제자 이름은 자격증에 기재되는 이름과 무관합니다.

## 자격증 실습
- 케어아카데미에서 취득하는 자격증 과정에는 실습이 포함되어 있지 않습니다.
