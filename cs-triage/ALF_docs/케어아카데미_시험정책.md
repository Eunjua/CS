# 케어아카데미 시험 정책

## 1. 응시 자격·조건

### 시험 응시 조건
- 시험은 수강율 50% 이상 달성 시 응시할 수 있습니다.
- 수강율 50%를 충족하지 못한 경우 시험에 응시할 수 없습니다.

### 응시 가능 기간
- 수강 신청일로부터 14일 내로는 언제든지 시험에 응시할 수 있습니다.
- 기한이 만료되면 시험에 응시할 수 없습니다.

## 2. 시험 방식

### 응시 방법
- 시험은 케어파트너 앱 또는 웹사이트의 강의실에서 응시합니다.
- 강의실 진입 후 '시험 보기' 메뉴를 통해 시험을 시작할 수 있습니다.
- 시험 응시 링크: https://www.carepartner.kr/academy/my

### 오프라인 응시 가능 여부
- 오프라인 시험은 운영하지 않습니다.
- 모든 시험은 케어파트너 앱 또는 웹사이트에서만 응시할 수 있습니다.

### 문항 수
- 시험은 총 20문항으로 구성됩니다.

### 시험 시간
- 시험 시간 제한은 없습니다.
- 응시 중 시간 제약 없이 문제를 풀 수 있습니다.

### 시험 중 이탈 시 처리
- 시험 응시 도중 창을 닫거나 페이지를 이탈한 경우, 진행 내용은 저장되지 않습니다.
- 이 경우 처음부터 다시 시험에 응시해야 합니다.

## 3. 재응시 정책

### 재응시 가능 여부
- 수강 유효기한 내에는 횟수 제한 없이 재응시 가능합니다.
- 불합격한 경우에도 수강 유효기한 내에서는 언제든지 다시 시험을 볼 수 있습니다.

### 재응시 비용
- 수강 유효기한 내 재응시는 추가 비용이 발생하지 않습니다.

## 4. 결과 확인

### 시험 점수 확인 방법
- 시험 점수는 케어파트너 앱 또는 웹사이트의 강의실에서 확인할 수 있습니다.

### 오답 확인 가능 여부
- 오답 내역은 제공하지 않습니다.
- 시험 결과는 점수만 확인할 수 있으며, 어떤 문제를 틀렸는지는 안내되지 않습니다.

## 5. 기출문제 ✅ 제공

- **모든 과정에 기출문제를 제공합니다.**
- 이용 조건: **강의를 50% 이상 수강**하시면 이용할 수 있습니다. (시험 응시 조건과 같은 기준입니다.)
- 이용 방법: **동영상 수강 화면에서 기출문제 풀이**를 하실 수 있습니다. 별도 메뉴나 신청이 필요하지 않습니다.
- ⚠️ **파일(PDF·문제집)로는 제공하지 않습니다.** "기출문제집 보내주세요 / 파일로 받을 수 있나요" 문의 시 → 파일 제공은 없고 수강 화면에서 바로 풀 수 있다고 안내합니다.
- 기출문제 풀이와 **오답 확인은 다릅니다.** 시험 응시 후 어떤 문제를 틀렸는지는 여전히 제공하지 않습니다(위 '오답 확인 가능 여부' 참조).
