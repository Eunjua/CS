# 자격증 발급 공통 정책

케어아카데미에서 발급하는 자격증 전반에 적용되는 공통 정책입니다.
자격증별 세부 정보(발급 기관, 등록번호, 응시 자격 등)는 각 자격증 상세 문서를 참조해 주세요.

## 1. 자격증 취득 조건

- 케어아카데미 자격증은 **연령 제한과 학력 제한 없이** 누구나 취득할 수 있습니다.
- 시험에서 **60점 이상**이면 합격입니다.

## 2. 자격증 유형

- 케어아카데미 자격증은 **상장형과 카드형이 한 세트로 함께 발급**됩니다.
- 유형을 선택하거나 한 가지만 발급받을 수는 없습니다.
  - **일반 자격증**: 상장형 + 카드형 세트 발급
  - **베이비시터 자격증**: 상장형 단독 발급 (발급 기관 정책에 따라 카드형 제작 불가)

## 3. 발급 비용

- 상장형 + 카드형 세트: **93,000원**
- 베이비시터 자격증 (상장형 단독): **83,000원**
- 택배 배송비는 발급 비용에 **포함**되어 있습니다.

## 4. 자격증 기재 정보

자격증에는 다음 정보가 기재됩니다.

- 성명
- 생년월일
- 과정명
- 발급일
- 등록번호

## 5. 자격증 사진

- 케어아카데미 자격증은 **사진 없이** 제작됩니다.
- 규격에 맞는 사진 준비가 번거롭고, 사진 노출을 꺼려하시는 분들도 계시며, 운영상 이유로 **입력한 정보와 공식 자격증 번호로 제작**됩니다.

## 6. 자격증 발급 절차

1. 시험 합격
2. 자격증에 기재될 정보와 배송지 입력 후 결제
3. 결제 완료 시 배송 예정일자 알림톡 발송
4. **결제일 기준 7일 이내 택배 배송** (달력 기준)

## 7. 자격증 재발급

- 자격증 재발급이 필요한 경우 **케어아카데미 고객센터**로 문의해 주세요.
- 재발급은 **상담원이 직접 안내**해드리고 있습니다.
