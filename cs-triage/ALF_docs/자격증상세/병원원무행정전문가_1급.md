# 병원원무행정전문가 1급 자격증 상세

## 1. 기본 정보
- 자격증명: 병원원무행정전문가
- 급수: 1급
- 발급 기관: 한국엔씨에스자격개발원(주)
- 등록번호: 2025-005095
- 강의 개수: 20강

## 2. 자격증 소개
병원원무행정전문가는 병원 접수와 입·퇴원, 진료비 관리 등 원무 업무의 흐름을 이해하고 고객 응대부터 구매·예산·시설 관리까지 병원 행정 전반을 지원하는 병원 행정 인력입니다.

## 3. 주요 업무
- 외래 접수·입퇴원 수속 안내
- 진료비 수납·청구 관리
- 고객 응대·병원 홍보
- 구매·예산·시설 관리

## 4. 활용 분야
- 병원·의원 원무과 (병원 원무 사무원)
- 의료기관 행정·총무 부서 (의료기관 행정 사무원)
- 병원·의원 상담·안내 부서 (병원 고객상담원)

## 5. 특이사항
- 보건복지부 국가면허인 「보건의료정보관리사」와는 다른 자격입니다. 병원원무행정전문가는 한국엔씨에스자격개발원(주)에서 발급하는 민간자격입니다.
