# 집합건물관리사 1급 자격증 상세

## 1. 기본 정보
- 자격증명: 집합건물관리사
- 급수: 1급
- 발급 기관: 한국엔씨에스자격개발원(주)
- 등록번호: 2025-000695
- 강의 개수: 20강

## 2. 자격증 소개
집합건물관리사는 오피스텔·상가·복합건물 같은 집합건물의 관리단 운영, 회계·민원, 시설 점검, 안전·보안 업무의 기본 흐름을 이해하고 건물 관리 현장을 지원하는 건물관리 전문인력입니다. 20강에 걸쳐 관리사무소 운영부터 공용부 시설 관리, 건물 이용자 응대까지 학습합니다.

## 3. 주요 업무
- 관리사무소 운영 지원 (입주자 응대, 공지, 문서 정리)
- 공용부 시설 상태 확인·점검 기록, 협력업체 대응
- 임차인·소유자 문의 접수 및 주차·보안·환경 관리 지원

## 4. 활용 분야
- 오피스텔 관리사무소
- 상가·복합건물 관리사무소
- 건물 시설관리·점검 업체
- 건물 운영·고객지원 업무
