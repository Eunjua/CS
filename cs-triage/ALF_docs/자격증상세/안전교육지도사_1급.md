# 안전교육지도사 1급 자격증 상세

## 1. 기본 정보
- 자격증명: 안전교육지도사
- 급수: 1급
- 발급 기관: 한국엔씨에스자격개발원(주)
- 등록번호: 2023-003800
- 강의 개수: 20강

## 2. 자격증 소개
안전교육지도사는 일상과 교육 현장에서 발생할 수 있는 위험요인을 이해하고, 대상과 환경에 맞는 안전교육을 기획·운영하는 안전교육 전문인력입니다. 생활·교통·화재·재난 안전부터 응급상황 대처와 디지털 생활 안전까지 학습하여 안전사고 예방을 돕습니다.

## 3. 주요 업무
- 학교·교육기관, 어린이집·유치원, 복지시설 대상 안전교육 강의
- 기업·공공기관, 지역사회 대상 안전교육 프로그램 기획·진행
- 안전 관련 기관·교육업체의 안전교육 지원

## 4. 활용 분야
- 학교·영유아 안전교육
- 복지시설 생활안전교육
- 기업·공공기관 안전교육
- 지역사회 안전교육·캠페인

## 5. 특이사항
- 케어아카데미의 안전지도사 1급, 학교안전지도사 1급과는 다른 별개 과정·자격증입니다. 이름이 비슷하므로 고객이 어떤 과정을 말하는지 확인이 필요합니다.
