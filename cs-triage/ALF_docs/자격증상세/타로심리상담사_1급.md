# 타로심리상담사 1급 자격증 상세

- 자격증명: 타로심리상담사
- 급수: 1급
- 발급 기관: 한국엔씨에스자격개발원(주)

## 2. 자격증 소개
타로심리상담사는 타로카드를 매개로 내담자의 고민과 심리를 탐색하고, 심리적 안정과 통찰을 얻을 수 있도록 돕는 상담 전문인력입니다.

## 3. 주요 업무
- 타로카드를 활용한 개인 심리상담 및 진로·인간관계 상담
- 내담자 내면 탐색 및 심리적 안정 방향 제시

## 4. 활용 분야
- 심리상담소
- 문화센터
- 사회복지관
- 청소년·복지시설
- 개인 창업(타로카페·상담소) 또는 프리랜서로 활동 가능

## 5. 특이사항
- 타로카드 기반 상담 도구 성격의 등록 민간자격으로, 심리학 기반 임상 심리상담 자격과는 다릅니다.
