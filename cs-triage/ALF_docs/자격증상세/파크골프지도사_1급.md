# 파크골프지도사 1급 자격증 상세

## 1. 기본 정보
- 자격증명: 파크골프지도사
- 급수: 1급
- 발급 기관: 한국엔씨에스자격개발원(주)
- 등록번호: 2026-005911
- 강의 개수: 20강

## 2. 자격증 소개
파크골프지도사는 파크골프의 규칙과 기본 스윙, 경기 운영을 바탕으로 시니어 등 대상별 지도법과 안전관리를 익혀, 생활체육 프로그램과 동호회에서 파크골프를 가르치는 생활체육 지도인력입니다.

## 3. 주요 업무
- 파크골프 입문자 대상 규칙·기본 스윙 레슨
- 시니어 생활체육 파크골프 프로그램 진행
- 동호회 코칭·운영 및 대회 진행·안전관리 지원

## 4. 활용 분야

- 생활체육센터
- 노인복지관
- 문화센터
- 지역 체육회
- 파크골프 동호회
