# 보험심사관리사 1급 자격증 상세

## 1. 기본 정보
- 자격증명: 보험심사관리사
- 급수: 1급
- 발급 기관: 한국엔씨에스자격개발원(주)
- 등록번호: 2024-004996
- 강의 개수: 20강

## 2. 자격증 소개
보험심사관리사는 보험상품과 계약 심사의 기본을 이해하고, 보험금 청구부터 지급 심사까지의 업무 흐름을 바탕으로 청구 서류와 위험요인을 검토하는 보험 실무 인력입니다. 고객 응대 사례와 디지털 심사 활용까지 관련 업무의 기초를 익힙니다.

## 3. 주요 업무
- 보험 약관·심사 결과 안내
- 보험계약 위험요인 검토
- 보험금 청구서류 확인
- 부정청구 의심 징후 확인

## 4. 활용 분야
- 민간 보험회사 (보험심사 사무원)
- 병원·의원 원무 부서 (보험 청구 담당자)
- 보험회사 상담 부서 (보험 고객상담원)

## 5. 특이사항
- 보험연수원의 「보험심사역」(국가공인 민간자격)과는 다른 자격입니다. 이름이 비슷해 혼동하기 쉽습니다.
- 보험심사간호사회에서도 같은 이름(보험심사관리사)의 자격 과정을 운영하고 있으나, 케어아카데미 과정은 한국엔씨에스자격개발원(주)에서 발급하는 별개의 민간자격입니다.
