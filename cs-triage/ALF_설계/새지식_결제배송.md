## FAQ

### 1. 자격증 발급비는 얼마예요?
- 동의어: 무료라더니 왜 돈을 내요 / 발급 금액은 얼마인가요 / 자격증 얼마예요 / 수수료가 얼마인가요 / 비싸요 / 부담돼요
- 답변:
  자격증 발급비는 93,000원이에요. 상장형과 카드형 세트이고, 택배 배송비가 포함돼 있어요.
  베이비시터 자격증은 상장형만 발급되어 83,000원이에요.
  강의 수강과 시험은 무료로 지원해 드리고 있어요. 자격증은 인증 기관에 수강생을 등록하고 실물 자격증을 만드는 과정에서 비용이 생겨 발급비를 받고 있어요.
- 메모: 기존 456603을 고쳐 씀. 국비 과정 무료는 FAQ에 넣지 않는다 — 일반 고객이 "나도 무료냐"로 오해할 수 있어 국비 여부는 조회로만(10/30 은주). "비싸요"는 이유 안내로 끝내고, 할인 요청이면 태스크가 상담원 연결(#21)

### 2. 기초생활수급자는 발급비 감면되나요?
- 동의어: 저소득층 할인 되나요 / 차상위 감면 / 수급자 혜택
- 답변:
  발급비 감면 제도는 없어요. 기초생활수급자·차상위 여부와 관계없이 발급비는 같아요.

### 3. 내일배움카드로 결제해도 되나요?
- 기존 395108 그대로 둔다.

### 4. 가족 카드나 가족 계좌로 결제해도 되나요?
- 동의어: 집사람 카드로 결제 / 딸 이름으로 입금 / 자녀 카드로 결제 / 남편 계좌로 입금 / 타인 명의 카드 / 다른 사람 계좌로 입금
- 답변:
  네, 가족 카드나 가족 계좌로 결제하셔도 돼요.
  카드로 결제하실 때는 결제 화면에서 「카드번호 직접 입력하기」를 눌러 카드를 등록해 주세요.
  계좌이체는 안내받은 입금 계좌번호로 보내 주시면 누구 명의로 보내셔도 돼요.
  결제하신 분 이름은 자격증에 들어가지 않아요.
- 메모: 기존 395107(타인 계좌)과 8/25 삭제한 타인 카드 FAQ를 합침(#15). 395107은 지운다

### 5. 입금할 때 받는 분 이름이 뭐로 나와요?
- 동의어: 예금주 이름이 안 떠요 / 받는 사람 이름이 이상해요 / 입금자명 / 수취인
- 답변:
  받는 분 이름은 "케어아카데미"로 나와요.
  이름이 뜨지 않으면 은행, 계좌번호, 금액이 안내받은 그대로인지 확인해 주세요. 하나라도 다르면 이체가 되지 않아요.
- 메모: 기존 395109를 고쳐 씀(#6)

### 6. 현금영수증 발급되나요?
- 채널톡에 있는 FAQ 그대로 둔다. "계좌이체로 결제 시 영수증은 자동으로 발급됩니다. 카드 결제 영수증은 카드사 거래내역에서 확인하실 수 있습니다."

### 7. 카드 할부를 일시불로 바꿀 수 있나요?
- 동의어: 무이자 할부로 했는데 / 할부 변경 / 일시불로 변경
- 답변:
  할부를 일시불로 바꾸는 건 카드사에서 하실 수 있어요. 이용하신 카드사 고객센터나 카드사 앱에서 변경해 주세요.

### 8. 자격증 먼저 받고 나중에 결제해도 되나요?
- 동의어: 후불 / 나중에 입금 / 받고 나서 결제
- 답변:
  먼저 받으실 수는 없어요. 자격증은 결제가 확인된 뒤에 제작해서 보내 드려요.

### 9. 자격증 결제하고 나서도 강의 계속 들을 수 있나요?
- 동의어: 결제 후에도 수강 / 결제하면 강의 끝나나요 / 계속 들어야 하나요
- 답변:
  네, 수강 기한 마감일까지는 계속 들으실 수 있어요.
- 메모: #27. 수강 단계에도 걸리는 질문이라 수강 단계 교체 때 중복 여부 다시 확인

### 10. 결제하면 자격증 받기까지 며칠 걸려요?
- 동의어: 배송 기간 / 입금만 하면 바로 나오나요 / 며칠 걸려요 / 어느 택배사로 와요 / 여러 개 신청하면 배송비
- 답변:
  결제하신 날부터 주말·공휴일을 빼고 7일 안에 받으실 수 있어요.
  CJ대한통운으로 보내 드려요.
  자격증을 여러 개 신청하시면 배송비는 자격증마다 포함돼 있어요.
- 메모: 결제 전·일반 질문용. "내 자격증 언제 와요·송장"처럼 이 고객의 배송은 태스크 트리거("배송/자격증 언제 오는지/송장")가 잡아 t2가 조회한다 — FAQ에는 배송 조회 안내를 넣지 않는다(10/30 은주)

### 11. 배송 날짜나 방법을 정할 수 있나요?
- 동의어: 우편함에 넣어 주세요 / 일반우편으로 / 늦게 보내 주세요 / 나중에 받을게요 / 다른 택배사로
- 답변:
  배송 날짜나 방법은 정할 수 없어요. 결제가 확인되면 순서대로 CJ대한통운 택배로 보내 드려요.
  우편함 배송, 일반우편, 발송 보류, 날짜 지정은 어려워요.

### 12. 실물 전에 스캔본이나 파일로 먼저 받을 수 있나요?
- 동의어: 모바일로 먼저 보게 해 주세요 / 이미지로 보내 주세요 / 사진 찍어서 / PDF / 파일로
- 답변:
  자격증은 실물로만 발급돼요. 파일이나 스캔본은 따로 보내 드리지 않아요.
  다만 결제를 마치셨고 채용 때문에 자격증이 오기 전에 제출해야 하신다면, 상담원이 확인해 드릴게요.
- 메모: #20. 예외 조건을 말하면 태스크가 상담원 연결

## 아티클

### 자격증 결제 방법 — 카드, 계좌이체(가상계좌), 할부

결제는 카드나 계좌이체(가상계좌) 중에서 고르실 수 있어요.

카드로 결제하시면 카드사에 따라 할부도 가능해요. 결제 중에 비밀번호를 물어보면, 카드 비밀번호 4자리가 아니라 처음 결제할 때 직접 정하는 결제용 비밀번호 6자리예요. 한 번 정하면 다음부터 같은 비밀번호로 결제하시면 돼요.

계좌이체를 고르시면 입금할 계좌번호가 카카오톡으로 와요. 내 자격증 관리 페이지에서도 볼 수 있어요. 자격증 신청을 마치고 결제 수단에서 계좌이체를 골라야 계좌번호가 만들어져요.

계좌이체는 나눠서 입금할 수 없어요. 계좌번호와 금액이 안내받은 것과 하나라도 다르면 이체가 되지 않으니 그대로 보내 주세요. 주말이나 공휴일에도 언제든 입금하실 수 있어요.

결제 대행은 토스페이먼츠가 맡고 있어요. 그래서 결제 완료 문자가 토스페이먼츠 이름으로 올 수 있는데, 정상이에요. 토스 계좌가 새로 만들어지거나 연회비가 생기지 않아요.

- 메모: 신청방법 결제 수단·PG, 수강정책 §7 비밀번호 6자리, 공통 §6 가상계좌 생성 조건을 합침. 빼는 것 — 수취인 표기 3종(#6, FAQ 5로), "새마을금고 미지원" 예시(10/30 은주: 새마을금고 있음 — 낡은 내용), 타인 카드 2가지 방법(#15, FAQ 4로), "결제 수단 변경은 채팅"(태스크 연결로), 영수증(FAQ 6으로), 분납 괄호 패치(본문 문장으로)
- 제목 단어: 고객이 쓰는 "결제·카드·계좌이체·가상계좌·할부"를 제목에 넣음

## 엑셀 (과목표) — 결제·배송에서 쓰는 칸

과목표 전체는 과목·자격증 정보 단계 교체 때 만든다. 결제·배송에서 필요한 칸만 먼저 정한다.

- 발급 형태: 상장형+카드형 세트 / 상장형만 (베이비시터)
- 발급비: 93,000 / 83,000 (베이비시터). 국비 과정 무료는 엑셀에도 적지 않는다 — 과정명이 같아 엑셀로는 구분이 안 되고, 봇이 먼저 말하면 일반 고객이 오해한다. 국비 여부는 태스크 조회로만
- 등록번호: 교통안전지도사 2024-001404, 재난안전지도사 2024-000186 (#11)

3. **[결제] 카드 안내 노드 문구 교체**: 타인 카드 2가지 방법 → FAQ 4와 같은 문장 하나. 결제 오류 문의는 이 노드 1회 안내 뒤 "안 돼요"면 연결
4. **t1-pend · t2-pend 문구 맞추기**: 거의 같은 문구 두 벌 → 한 문구로
