| 민간자격증_안내 | 다루는/안 다루는 자격증, 등록민간자격 신뢰성, 수료증≠자격증, 명칭 | 2026-06-24 등록 |
| 자격증_발급_공통정책 | 취득조건(60점), 유형(상장+카드), 비용(93,000/83,000), 기재정보, 사진無, 발급절차, 재발급 | 2026-06-24 등록 |
| 자격증_신청방법 | 신청시점·경로, 비용, 배송7일, 입력정보, 실습無 | 2026-06-24 등록 |
| 케어아카데미_수강정책 | 수강방법·로그인, 유효기한, 강의구성, 교육자료(PDF), 수강취소, 시험응시 | 2026-06-24 등록 |

| 자격증상세/ (폴더, 35종) | 과목별 기본정보·소개·주요업무·활용분야·특이사항·상세URL | 2026-06-24 등록 |

> - 노인돌봄생활지원사·학교안전지도사: 케어파트너 일자리 알림 제공 자격증(전국 전수 아님)
> - 안전지도사: 국가자격 '산업안전지도사'와 **다른** 민간자격 (이름 혼동 주의)
> - 베이비시터: 상장형 단독(카드형 불가), 유효기간 3년·갱신 5년/25,000원, **아이돌보미와 다름**
> - 산후관리사: '산모·신생아건강관리지원사업'과 **무관** (별도 양성과정 필요)
> - 발급기관 예외: 일상돌봄매니저·시니어웰니스전문가 = **한국검정평가원** (그 외 대부분 한국엔씨에스자격개발원)

## 🔧 분석 절차 (스킬이 자동 수행)

1. `상담내역/` 새 파일 수집 (`처리완료/` 제외)
2. 구분기준 통합본 + ALF_rules 7종 기준으로 한 건씩 판정
3. 유형 분류(①/②-A/②-B/③) + 응대 ✅⚠️❌ + 이관 적정성
4. 고칠 규칙 제안 → 승인 후 `ALF_rules/*.md` 반영
5. 이 로그에 회차 누적 + 현황 요약 갱신
6. 분석 끝난 파일 → `처리완료/` 이동
